## Overview

**Page Purpose:** Comprendre l'état complet de la boutique en moins de 5 secondes — CA d'hier, alertes qui demandent une décision, signaux faibles (stock, fraîcheur).

**Entry Context:** Arrive depuis le tap sur la notification push "Résumé d'hier" (étape 01.1). Session active, profil "Blandine — Propriétaire" déjà chargé. L'app s'ouvre directement sur cette vue (deep link).

**Exit Action:** Tape la tuile / le bouton "Voir les rapports" (ou "Rapports") → Hub rapports (étape 01.3).

**On-Page Interactions (storyboard items):**
- **Pull-to-refresh** → resync cloud, mise à jour des chiffres
- Tap **"Commande à valider"** → deep link vers Validation commande (hors scénario 01)
- Tap **"Écart caisse"** → deep link vers Arrêt de caisse du jour (hors scénario 01)
- Tap badge **"Alertes stock"** → deep link vers Alertes stock (hors scénario 01)
- **Switch période** (Hier / 7 jours / Mois) → recalcul des KPIs sans quitter la page

**Contenu clé visible en 5s:**
- CA d'hier (47 500 F) avec delta vs avant-hier
- Nombre de ventes + ventilation par mode de paiement
- Tuile alertes : commandes à valider, écarts caisse, stock bas, produits fraîcheur rouge
- Bouton/tuile "Rapports" comme exit action principale
