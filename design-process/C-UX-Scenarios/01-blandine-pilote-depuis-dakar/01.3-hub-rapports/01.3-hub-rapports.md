# 01.3 — Hub rapports

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Blandine pilote depuis Dakar |
| **Page Number** | 01.3 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Présenter le catalogue de rapports disponibles (CA, Stock, Pertes, Ventes par vendeur, etc.) et permettre à Blandine de choisir lequel consulter pour creuser un signal repéré sur le dashboard.

**Entry Context:** Arrive depuis le tap "Voir les rapports" sur le Dashboard Patron (étape 01.2).

**Exit Action:** Tape la tuile **"Rapport CA"** → Rapport CA (étape 01.4).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports`
- Mobile : back button + titre "Rapports"

**On-Page Interactions (storyboard items):**
- **Filtre période global** (Aujourd'hui / 7 jours / Mois / Custom) appliqué à tous les rapports en aval
- **Recherche** dans la liste des rapports
- Tap **"Exporter PDF"** depuis le hub → flow d'export rapide (utilisé en étape 01.7 au retour)
- Tap autres rapports (Stock, Pertes, Vendeurs, Modes paiement) → chacun ouvre son rapport

**Contenu clé:**
- Liste/grille de tuiles : Rapport CA, Rapport Stock, Rapport Pertes, Rapport Ventes par vendeur, Rapport Modes de paiement
- Chaque tuile montre 1 KPI résumé (ex: "CA semaine : 312 400 F")
- Bouton global "Exporter & partager"
