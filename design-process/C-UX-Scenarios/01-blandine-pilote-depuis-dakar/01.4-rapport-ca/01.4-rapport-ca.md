# 01.4 — Rapport CA

## Page Metadata

| Property | Value |
|----------|-------|

| **Page Number** | 01.4 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Voir la performance commerciale sur 7 jours — courbe du CA par jour, ventilation par mode de paiement, par vendeur, total et delta semaine précédente. Blandine confirme que la semaine est correcte (ou pas).

**Entry Context:** Arrive depuis le tap "Rapport CA" sur le Hub rapports (étape 01.3). La période "7 derniers jours" est pré-sélectionnée depuis le filtre global.

**Exit Action:** Tape l'onglet/lien **"Rapport stock"** dans la barre de navigation entre rapports → Rapport stock (étape 01.5).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports > CA`
- Mobile : back button + titre "Rapport CA" + tabs entre rapports

**On-Page Interactions (storyboard items):**
- **Switch période** (Hier / 7j / Mois / Custom) → recalcul des KPIs
- Tap sur un jour de la courbe → drill-down ventes du jour (hors scénario)
- **Filtre vendeur** → focus sur un commercial
- **Filtre mode de paiement** → focus Cash / Wave / Orange Money / Crédit
- Bouton **"Exporter ce rapport"** (utilisé en 01.7)

**Contenu clé:**
- KPI principal : CA total semaine + delta vs semaine précédente (vert/rouge)
- Courbe CA par jour
- Ventilation par mode de paiement (donut)
- Top vendeurs (liste)
- Nombre de tickets + panier moyen
