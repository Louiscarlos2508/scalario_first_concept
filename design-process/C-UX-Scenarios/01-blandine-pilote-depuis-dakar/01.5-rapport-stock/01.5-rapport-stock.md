# 01.5 — Rapport stock

| Property | Value |
|----------|-------|

## Overview

**Page Purpose:** Vérifier la valeur totale du stock, les mouvements de la semaine, et identifier les produits critiques (stock bas, fraîcheur rouge). Blandine s'assure qu'aucun produit clé n'est en rupture imminente.

**Entry Context:** Arrive depuis l'onglet "Rapport stock" sur le Rapport CA (étape 01.4). Période "7 derniers jours" héritée du filtre global.

**Exit Action:** Tape l'onglet **"Rapport pertes"** dans la nav entre rapports → Rapport pertes (étape 01.6).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports > Stock`
- Mobile : back button + titre "Rapport stock" + tabs entre rapports

**On-Page Interactions (storyboard items):**
- **Switch période**
- Tap sur un produit critique → fiche produit (hors scénario)
- **Filtre par catégorie** (Fruits / Légumes / Épices)
- **Tri** par valeur stock / par rotation / par fraîcheur
- Bouton **"Exporter ce rapport"** (utilisé en 01.7)

**Contenu clé:**
- KPI principal : valeur stock totale + delta vs semaine précédente
- Nombre de références + total quantités
- Top produits par valeur immobilisée
- Liste produits critiques (stock bas / fraîcheur rouge) — code couleur visible
- Mouvements de la semaine (entrées / sorties / ajustements)
