# 01.7 — Export & partage WhatsApp

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Blandine pilote depuis Dakar |
| **Page Number** | 01.7 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Générer le PDF des rapports consultés (CA + Stock + Pertes sur 7 jours) et le partager directement au comptable via WhatsApp. C'est la victoire finale du scénario — Blandine a une preuve tangible et l'a transmise.

**Entry Context:** Arrive depuis le retour Hub rapports (après 01.6 Rapport pertes). Le tap sur "Exporter & partager" ouvre cette vue (modal ou page selon device).

**Exit Action:** Tape **"Envoyer sur WhatsApp"** → ouvre le share sheet Android avec le PDF en pièce jointe → sélectionne le contact comptable → confirme l'envoi → message envoyé ✓ (succès du scénario).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports > Exporter`
- Mobile : modal plein écran avec close

**On-Page Interactions (storyboard items):**
- **Sélection des rapports à inclure** (cases à cocher pré-cochées : CA, Stock, Pertes)
- **Choix période** (héritée par défaut : 7 derniers jours)
- **Choix format** : PDF / Image / Lien partageable
- **Aperçu PDF** avant envoi (preview scrollable)
- **Choix canal** : WhatsApp (default) / Email / Téléchargement local / Lien copiable
- État de génération : "Génération du PDF..." → "Prêt à partager"

**Contenu clé:**
- En-tête : nom boutique, période, date génération
- Récap exécutif (top 3 KPIs)
- Section CA, Section Stock, Section Pertes
- Pied de page : généré par Scalario, signature Blandine

**Succès final visible:**
- Toast : "Rapport partagé avec [Nom comptable]"
- Retour automatique au Dashboard
