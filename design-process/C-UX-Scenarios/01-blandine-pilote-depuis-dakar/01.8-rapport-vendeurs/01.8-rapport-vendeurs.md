# 01.8 — Rapport vendeurs

## Page Metadata

| Property | Value |
|----------|-------|

## Overview

**Page Purpose:** Comparer la performance commerciale de chaque vendeur sur la période (CA, nombre de tickets, panier moyen, taux de remise) pour identifier les top performers et ceux qui ont besoin de soutien. Blandine repère qui pousse les ventes et qui décroche.

**Entry Context:** Arrive depuis l'onglet "Vendeurs" sur n'importe quel rapport (Hub 01.3 ou détail 01.4/01.5/01.6). Période "7 derniers jours" héritée du filtre global.

**Exit Action:** Tape l'onglet **"Paiements"** dans la nav entre rapports → Rapport paiements (étape 01.9).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports > Vendeurs`
- Mobile : back button + titre "Rapport vendeurs" + tabs entre rapports

**On-Page Interactions (storyboard items):**
- **Switch période**
- Tap sur un vendeur → fiche vendeur détaillée (hors scénario)
- **Tri** par CA / par tickets / par panier moyen / par taux de remise
- **Filtre rôle** (Vendeur · Caissier · Manager)
- Bouton **"Exporter & partager"**

**Contenu clé:**
- KPI principal : meilleur vendeur de la période + delta vs sem. précédente
- Nombre de vendeurs actifs + total tickets émis
- Classement complet (avatar, nom, CA, tickets, panier moyen, % remise)
- Mise en évidence visuelle du top 3 (médailles or/argent/bronze)
- Insights auto : régularité / pic de performance / vendeur en baisse
