# 01.9 — Rapport modes de paiement

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Blandine pilote depuis Dakar |
| **Page Number** | 01.9 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Comprendre la répartition des encaissements par mode de paiement (Cash, Wave, Orange Money, Crédit) pour suivre les tendances mobile money, contrôler les créances clients et préparer le rapprochement comptable.

**Entry Context:** Arrive depuis l'onglet "Paiements" sur n'importe quel rapport (depuis 01.8 dans le scénario, ou depuis le Hub 01.3). Période "7 derniers jours" héritée.

**Exit Action:** Tape **"Exporter & partager"** → Export & partage (étape 01.7) — boucle finale du scénario.

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Rapports > Paiements`
- Mobile : back button + titre "Rapport paiements" + tabs entre rapports

**On-Page Interactions (storyboard items):**
- **Switch période**
- Tap sur un mode de paiement → liste des transactions du mode (hors scénario)
- **Filtre statut** (Encaissé / En attente / Refusé)
- Bouton **"Voir les crédits ouverts"** (raccourci vers le suivi créances)
- Bouton **"Exporter & partager"**

**Contenu clé:**
- KPI principal : total encaissé + part mobile money vs cash
- Donut répartition par mode (Cash / Wave / Orange Money / Crédit)
- Tableau détail : nombre de transactions, montant total, frais, montant net par mode
- **Encart Crédit** : créances ouvertes, top débiteurs, ancienneté moyenne
- Tendance mobile money sur 4 semaines (mini sparkline)
- Insights auto : mode en hausse, créances à relancer, frais Wave/OM cumulés
