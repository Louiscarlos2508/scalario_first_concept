# 01.1 — App Init

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 01: Blandine's Morning Read |

| **Platform** | Mobile Android (Tecno/Infinix, Snapdragon 680) — dark mode |

## Overview

**Page Purpose:** L'app se lance et charge les données locales Drift immédiatement — Blandine voit un contenu réel dès le premier frame, sans skeleton screen bloquant.

**Entry Context:** Premier step — départ du scénario. Blandine ouvre l'app depuis l'icône installée.

**Exit Action:** Dashboard OWNER s'affiche avec données J-1 → Blandine passe au step 01.2.

**On-Page Interactions:**
- `SplashScreen` affiche logo monogramme Sc (2 sec max)
- `SyncStatusBar` initialise en arrière-plan (connexion réseau vérifiée)
- Drift local DB chargée → données disponibles sans attendre le backend
- Si réseau disponible : sync silencieuse en arrière-plan, pas bloquante

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Blandine, commerçante fruits et légumes, Ouagadougou. 7h du matin, avant l'ouverture du magasin. Téléphone en main, plein air, connexion 4G variable.

**Mental State (Q4):**
- Hope: Voir que tout va bien, ouvrir la journée sereinement
- Worry: Découvrir une anomalie qu'elle aurait pu voir plus tôt

**Discovery Method (Q6):** Ouvre l'app depuis l'icône → unlock rapide (fingerprint / Face ID / PIN selon appareil + config tenant) → dashboard immédiat. Pas de re-saisie credentials complets.
