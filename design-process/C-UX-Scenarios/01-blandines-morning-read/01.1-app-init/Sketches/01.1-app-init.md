# Sketch Hi-Fi — 01.1 App Init

> Point d'entrée de toute session Scalario.
> Blandine déverrouille l'app le matin avec son empreinte.
> Le système Android gère la biométrie — Scalario ne voit que le résultat (succès / échec).

---

## Conventions de ce sketch

```
Inter 14sp text-body · Inter 12sp text-caption · Inter 22sp font-page-title
Roboto Mono 28sp font-kpi-value
_texte_   = Inter text-caption color-neutral-500 (hint / secondaire)
[●]       = empreinte / cercle rempli
[○]       = PIN digit vide
[◉]       = PIN digit saisi (masqué)
███       = fond plein (ActionButton primaire)
░░░       = skeleton shimmer (bg color-neutral-100)
```

### Comportements & Règles

| Situation | Comportement |
|-----------|-------------|
| Empreinte échoue 1× | Vibreur court + "Réessayez" sous le container |
| Empreinte échoue 3× | Fallback automatique → État 2 (PIN) |
| PIN échoue 5× | Logout complet → État 5 (login username + MDP) |
| Drift cache vide + hors ligne | → ErrorState plein écran "Connexion requise" (voir 09-loading-states.md) |
| Token expiré | → État 5 avec AlertBanner "Session expirée — reconnectez-vous" |
| Après auth réussie | → État 3 transition → État 4 Drift load → S01.2 Dashboard |
| Premier login (MDP temp) | → S23.1 Forced Password Change (bloquant) |
| Biométrie pas configurée | → État 2 PIN directement |
| PIN pas configuré non plus | → État 5 login complet |
