# 02.2 — Sélection Articles

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 02: Commercial's Quick Sale |
| **Step** | 02.2 |
| **Platform** | Mobile Android mid-range — usage debout, une main |

## Overview

**Page Purpose:** Le Commercial sélectionne les articles vendus et ajuste les quantités — depuis le catalogue JSON du stock disponible.

**Entry Context:** Vient de 02.1 Dashboard COMMERCIAL via tap `ActionButton` "Nouvelle vente".

**Exit Action:** Tap "Confirmer la sélection" → step 02.3.

**On-Page Interactions:**
- `ProductSelector` — liste articles depuis JSON stock (nom, prix unitaire, quantité disponible)
- Tap article → sélectionné + quantité ajustable (+/-)
- Panier en bas : montant courant (Roboto Mono) mis à jour en temps réel
- Touch targets 48dp min — usage une main debout
