# 02.3 — Confirmation Paiement

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 02: Commercial's Quick Sale |
| **Step** | 02.3 |
| **Platform** | Mobile Android mid-range — usage debout, une main |

## Overview

**Page Purpose:** Le Commercial confirme le montant total et valide le paiement cash — la `TransactionLine` est enregistrée, le stock mis à jour automatiquement.

**Entry Context:** Vient de 02.2 Sélection Articles via tap "Confirmer la sélection".

**Exit Action:** Tap "Valider la vente" → transaction enregistrée, retour Dashboard COMMERCIAL ✓

**On-Page Interactions:**
- `PaymentConfirm` — montant total en Roboto Mono très grand, récap articles
- Mode paiement : cash (Phase 1) — sélectionnable par JSON Phase 2 (Wave, Orange Money)
- Tap "Valider la vente" → feedback succès (`AlertBanner` vert 2 sec) → retour dashboard
