### Règle irréversibilité (→ ux-rules/principles.md P10)

```
"Valider la vente" = action irréversible → PAS de ConfirmationDialog
car les données sont affichées clairement AVANT le tap.
Le récap articles + total = la confirmation visuelle.
Un ConfirmationDialog ici ajouterait de la friction inutile (P5 violation).
Exception : si montant > seuil configurable (ex: 500 000 FCFA) → dialog.
```
