# 02.1 — POS Vente détail

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 02: Vivien encaisse une vente |
| **Page Number** | 02.1 |
| **Platform** | Tablette / téléphone Android partagé sur comptoir |

## Overview

**Page Purpose:** Construire le panier d'une vente — recherche rapide produit, ajout en 1 tap, voir le total se mettre à jour en temps réel.

**Entry Context:** Page POS toujours ouverte pendant les heures d'ouverture. La cliente pose les produits sur le comptoir, Aïcha tape directement dans la barre de recherche.

**Entrées alternatives au POS:**
- **Profil Vendeuse** : POS = écran d'accueil par défaut, toujours ouvert.
- **Profil Patron (Vivien)** : POS accessible depuis le backoffice patron via un bouton dédié "POS / Encaisser" — Vivien peut prendre le relais ou faire une vente lui-même quand il est sur place.

**Exit Action:** Tape le bouton **"Encaisser"** (sticky bottom avec total) → Sélection mode de paiement (étape 02.2).

**Navigation:**
- **Breadcrumb desktop:** `Boutique > POS`
- Mobile : titre "POS" + accès profil/menu

**On-Page Interactions (storyboard items):**
- **Recherche texte** (autocomplete sur nom produit)
- **Scan code-barres** caméra (mobile_scanner)
- **Catégories rapides** (chips horizontales) pour filtrer
- **Tap produit** → ajout panier qté 1
- **+/− qté** dans le panier
- **Suppression ligne** (swipe ou tap croix)
- **Vider panier** (action header)
- **Notes vente** (optionnel)
- **Switch détail/gros** (sur produits éligibles)

**Contenu clé:**
- Barre de recherche en haut (focus auto)
- Grille/liste produits avec photo + prix + stock
- Panier latéral (desktop) ou bottom sheet (mobile) — lignes + total
- Sticky **"Encaisser • 3500 F"** en bas

## First Step Context

### User Situation (Q3)
Aïcha, vendeuse de Vivien, boutique cosmétiques de Ouagadougou. 14h30 mardi. Une cliente arrive avec une crème + un savon. Vivien absent. Téléphone pro sur le comptoir, imprimante thermique appairée. Cliente avec billet 5000 F en main.

### Mental State (Q4)
- **Hope:** Encaisser vite, donner une vraie facture, ne pas faire attendre.
- **Worry:** Bloquer sur la recherche, se tromper de prix, imprimante muette devant la cliente.

### Device (Q5)
Tablette ou téléphone Android partagé, profil "Aïcha — Vendeuse" actif.

### Discovery Method (Q6)
Le POS est déjà ouvert (vue d'accueil par défaut pour le profil vendeuse). Aïcha n'a rien à lancer — la cliente arrive, elle tape la recherche.
