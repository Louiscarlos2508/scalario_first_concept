# 02.3 — Confirmation facture

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 02: Vivien encaisse une vente |
| **Page Number** | 02.3 |
| **Platform** | Tablette / téléphone Android partagé sur comptoir |

## Overview

**Page Purpose:** Récapituler la vente une dernière fois, déclencher l'impression thermique Bluetooth, confirmer que tout est OK avant de tendre la facture à la cliente. C'est le moment "preuve de pro" qui différencie Scalario du cahier.

**Entry Context:** Aïcha vient de valider le paiement Cash 5 000 F (étape 02.2). La cliente attend sa facture.

**Exit Action:** Tape **"Imprimer & terminer"** → impression thermique → toast succès → retour POS vide (étape 02.1) ✓

**Navigation:**
- **Breadcrumb desktop:** `Boutique > POS > Confirmation`
- Mobile : pas de back (vente verrouillée), titre "Vente · Récap"

**On-Page Interactions (storyboard items):**
- **Aperçu reçu** (preview du ticket thermique 58mm)
- Bouton **"Imprimer & terminer"** (action principale)
- Bouton secondaire **"Envoyer par WhatsApp"** (alternative dématérialisée)
- Bouton secondaire **"Imprimer 2e copie"** (après impression)
- État impression : Idle → En cours → Succès / Erreur (imprimante non trouvée)
- Toast final **"Vente enregistrée · Stock mis à jour"**

**Contenu clé:**
- Récap vente : numéro ticket, date/heure, vendeuse, mode paiement, monnaie rendue
- Aperçu ticket thermique : logo Scalario, nom boutique, lignes produits, totaux, "Merci !"
- État imprimante (connectée / déconnectée)
- CTA principal pleine largeur
- Après succès : écran confirmation avec numéro ticket + retour POS

## States à maquetter

1. **Default M** — récap + preview ticket + CTA "Imprimer & terminer"
2. **Impression en cours M** — bouton avec spinner + feedback imprimante
3. **Succès M** — checkmark vert + ticket #2026-0142 + retour POS auto dans 3s
4. **Erreur imprimante M** — modal "Imprimante non trouvée" + Réessayer / Envoyer WhatsApp
5. **Default Tablette/Desktop** — layout 2 colonnes : récap+actions à gauche, preview ticket à droite
