# 03.1 — Splash Screen · Phase 4 UX Spec

## Identité de la page
- **Nom** : Splash Screen
- **Scénario** : 03 — Bernard Découvre Scalario Seul
- **Persona** : Bernard (nouveau commerçant, découverte autonome)
- **Plateforme** : Mobile (390×844)
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Accueillir Bernard à son premier lancement de l'app. Installer la confiance et l'identité de la marque avant l'inscription.

## Point d'entrée
Premier lancement de l'application mobile Scalario (post-installation depuis store).

## État mental de l'utilisateur
Curieux, légèrement hésitant. "Est-ce que cet outil est sérieux ? Est-ce fait pour quelqu'un comme moi ?"

## Résultats attendus
- Bernard voit le logo Scalario (wordmark complet) et comprend qu'il s'agit d'un produit professionnel
- La tagline lui parle directement ("Gérez votre boutique. Sachez ce qui se passe. Depuis n'importe où.")
- Il clique sur "Commencer" avec confiance

## Éléments UI
| Élément | Description |
|---|---|
| Fond | `#0f172a` — dark navy, premium |
| Wordmark SVG | S arcs multicolores + "CALARIO" en Bebas Neue blanc |
| Tagline | 3 lignes, blanc 50%, centrée |
| Dots animés | 3 points rebondissants — loading playful |
| CTA | Bouton blanc pleine largeur "Commencer", pulse glow |
| Legal | Mention conditions d'utilisation, blanc 25% |

## Animations
- Wordmark + tagline : fade-up 0.8s, délai 0.3s / 0.7s
- Bottom (dots + CTA) : fade-up 0.8s, délai 1.1s
- CTA glow pulse : 2s infinite, démarre à 1.8s
