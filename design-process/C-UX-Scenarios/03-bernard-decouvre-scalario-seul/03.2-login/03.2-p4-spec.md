# 03.2 — Login / Inscription · Phase 4 UX Spec

## Identité de la page
- **Nom** : Connexion / Création de compte
- **Scénario** : 03 — Bernard Découvre Scalario Seul
- **Persona** : Bernard (nouveau commerçant, invitation intégrateur)
- **Plateforme** : Mobile (390×844)
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Bernard de créer son compte rapidement avec les informations pré-remplies par l'intégrateur, sans friction.

## Point d'entrée
CTA "Commencer" depuis l'écran splash (03.1).

## État mental de l'utilisateur
Motivé mais vigilant. "Est-ce que ça va être long ? Je veux juste essayer l'app."

## Résultats attendus
- Bernard voit que l'intégrateur a déjà configuré sa boutique (bannière verte)
- Il remplit son nom + téléphone (ou les trouve pré-remplis)
- Il crée son compte en 1 tap → vers l'onboarding wizard

## Éléments UI
| Élément | Description |
|---|---|
| Tab switcher | "Créer un compte" (actif) / "Se connecter" |
| Bannière invitation | Verte, intégrateur + nom boutique pré-configurée |
| Champ nom | Pré-rempli si invitation |
| Champ téléphone | Pré-rempli + check vert si validé |
| Champ boutique | Grisé (pré-config intégrateur, read-only) |
| Champ mot de passe | Avec toggle visibilité |
| CTA principal | Bleu "Créer mon compte" |
| Option secondaire | "Continuer avec le téléphone (OTP)" |
| Monogramme | Sc (S arcs + c arc `#1A1A1A`) dans top bar — fond blanc |

## Navigation
- Retour : chevron gauche → splash
- Succès : → 03.3 Onboarding Wizard
