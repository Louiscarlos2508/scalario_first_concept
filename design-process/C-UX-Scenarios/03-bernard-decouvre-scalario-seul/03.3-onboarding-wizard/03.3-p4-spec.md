# 03.3 — Onboarding Wizard · Phase 4 UX Spec

## Identité de la page
- **Nom** : Onboarding Wizard — Configuration & Première vente
- **Scénario** : 03 — Bernard Découvre Scalario Seul
- **Persona** : Bernard (standard, autonome post-invitation intégrateur)
- **Plateforme** : Mobile (390×844)
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Bernard de compléter sa configuration en 3 étapes guidées sans friction, puis réaliser sa première vente test pour valider que tout fonctionne.

## Architecture à 2 couches (décision clé)
- **Couche intégrateur (template)** : définit ce qui est *possible* — modules on/off, contraintes business. Verrouillée pour le client.
- **Couche client** : configure ce qui est *autorisé* — produits, paramètres dans les limites du template.
- **L'IA opère uniquement dans la couche client** : si un produit décrit correspond à un module désactivé, l'IA signale le conflit et renvoie vers l'intégrateur. Elle ne modifie jamais le template.

## Point d'entrée
Compte créé (03.2) → redirection automatique vers l'onboarding.

## État mental de l'utilisateur
Motivé mais pressé. "Je veux juste voir si ça marche."

## Résultats attendus
- Bernard comprend ce que l'intégrateur a préparé pour lui
- Il ajoute ses produits réels via le chat IA (zero friction)
- Il fait une vente test et voit que ça marche → premier "wow moment"

## 4 panels

### Panel 1 — Boutique (template intégrateur)
- Card template verrouillée : nom boutique, localisation, modules on/off
- Note jaune : "Pour modifier les modules, contactez votre intégrateur"
- CTA : "C'est bon, continuer"

### Panel 2 — IA Chat produits
- Chat conversationnel : Bernard décrit ses produits en langage naturel
- L'IA identifie les produits + attributs (unité, volume, catégorie) et les affiche en carte verte
- **Carte de conflit** (orange) : si produit hors template → "Module non activé · contactez votre intégrateur"
- Options : import CSV/Excel, modification manuelle
- CTA : "Confirmer les produits"

### Panel 3 — Première vente test
- Panier avec les produits nouvellement créés
- Contrôles quantité +/−
- Choix mode paiement (chips : Espèces, Orange Money, Moov Money)
- CTA : "Valider la vente test"

### Panel 4 — Succès
- Icône verte, message "Vous êtes prêt !"
- Récapitulatif : boutique, produits configurés, vente test
- Note : "La vente test ne figure pas dans vos rapports réels"
- CTA vert : "Aller au tableau de bord"
