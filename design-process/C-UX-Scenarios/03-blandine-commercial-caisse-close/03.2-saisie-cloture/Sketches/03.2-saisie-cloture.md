# Sketch Hi-Fi — 03.2 Saisie Clôture

### Calcul écart temps réel

```
écart = montant_saisi - montant_système
  > 0  → "Excédent"  — ambre (plus de cash que prévu)
  = 0  → "Équilibrée" — vert
  < 0  → "Manque"    — ambre (mineur) ou rouge (significatif)

Seuil mineur vs significatif : JSON config tenant (ex: abs(écart) < 5000 = mineur)
Calcul : en local Drift, pas de réseau requis, temps réel < 16ms
```

### Règles UX formulaire

```
1. Montant système = lecture seule — jamais modifiable par Commercial
2. NumberInput focus auto au chargement de l'écran
3. Clavier numérique Android (inputType = numberDecimal) — pas de virgule
4. CTA désactivé tant que champ vide
5. Écart significatif → note obligatoire AVANT activation CTA
6. Pas de ConfirmationDialog — récap système + saisie = confirmation visuelle (P5)
7. Exception ConfirmationDialog : seulement si écart > seuil critique extrême (ex: > 50 000 FCFA)
```
