# 03.3 — Dashboard OWNER — Validation

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 03: Blandine & Commercial's Caisse Close |
| **Step** | 03.3 |
| **Platform** | Mobile Android mid-range — Blandine hors magasin possible |

## Overview

**Page Purpose:** Blandine ouvre l'app depuis la push notification, voit le récap de clôture, compare les montants, et valide — sans confrontation directe avec le Commercial.

**Entry Context:** Vient de push FCM "Clôture soumise par [Commercial]" → tap notification → app ouverte directement sur le `ConfirmationDialog`.

**Exit Action:** Tap "Valider la clôture" → `AlertBanner` vert "Clôture validée" → clôture archivée ✓

**On-Page Interactions:**
- `ConfirmationDialog` — montant saisi par Commercial vs montant système (Roboto Mono)
- Écart affiché clairement (vert/ambre/rouge selon valeur)
- `ActionButton` "Valider" + `ActionButton` secondaire "Signaler un problème"
- Post-validation : `AlertBanner` vert 2 sec → retour Dashboard OWNER
