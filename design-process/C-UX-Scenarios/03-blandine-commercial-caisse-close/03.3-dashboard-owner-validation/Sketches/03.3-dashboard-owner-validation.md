> Blandine reçoit une push FCM "Clôture soumise par Kofi".

### Règle d'inversion CTA selon écart

```
Écart = 0 ou mineur (< seuil JSON) :
  Primaire  : "Valider la clôture" → bg #FFCC00 color-neutral-900
  Secondaire: "Signaler un problème" → bg color-neutral-100

Écart significatif (> seuil JSON) :
  Primaire  : "Signaler un problème" → bg #FFCC00 color-neutral-900
  Secondaire: "Valider malgré l'écart" → bg color-danger-500 color-white
  Logique   : on oriente Blandine vers l'action la plus prudente
```
