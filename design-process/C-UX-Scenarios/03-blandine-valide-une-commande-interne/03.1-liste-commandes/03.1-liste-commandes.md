# 03.1 — Liste commandes internes

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 03: Blandine valide une commande interne |
| **Page Number** | 03.1 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Voir d'un coup d'œil toutes les demandes de commande interne (créées par les commerciaux, en attente d'approbation gérante puis patronne), filtrer par statut, identifier celles qui nécessitent une action.

**Entry Context:** Blandine reçoit une notification push "1 commande à valider" depuis Dakar. Tap → atterrit sur cette liste avec le filtre "À valider" pré-actif.

**Exit Action:** Tape une commande dans la liste → Détail commande (étape 03.2).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Commandes internes`
- Mobile : back button + titre "Commandes internes" + FAB ⊕ (rôle commercial uniquement)

**On-Page Interactions (storyboard items):**
- **Tabs statut** : À valider · En cours · Validées · Refusées
- **Tap commande** → détail (03.2)
- **Recherche** par n° commande / produit
- **Filtre commercial** (qui a créé)
- **Tri** date / urgence / montant
- **Pull-to-refresh**
- Badge compteur "À valider"
- **FAB ⊕** (visible uniquement pour commerciaux)

**Contenu clé:**
- KPI bar : 3 à valider · 8 en cours · 24 validées (semaine)
- Cards commandes : n°, créateur, étape (workflow visible), produits résumés, montant estimé, date, badge urgence
- Mise en évidence des "À valider par toi" (border bleu)
- Empty state : "Aucune commande en attente"

## States à maquetter

1. **Default M** — tab "À valider" actif, 3 commandes dont 1 "À valider par toi"
2. **Tab Validées M** — historique, 4 commandes validées
3. **Empty M** — "Aucune commande en attente"
4. **Filtres modal M** — filtrer par commercial / urgence / montant
5. **Default Desktop** — 2 colonnes : KPI bar + tableau commandes avec workflow visuel
