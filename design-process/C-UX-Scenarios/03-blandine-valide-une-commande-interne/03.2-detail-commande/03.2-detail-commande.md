# 03.2 — Détail commande interne

## Page Metadata

| Property | Value |
|----------|-------|

## Overview

**Page Purpose:** Lire en détail une demande de commande : qui l'a créée, ce qu'elle contient, pourquoi (motif commercial), où elle en est dans le workflow (commercial → gérante → patronne). Donner à Blandine toutes les infos pour décider en confiance.

**Entry Context:** Blandine vient de taper une commande "À valider par toi" depuis 03.1. La gérante a déjà approuvé.

**Exit Action:** Tape **"Valider"** ou **"Refuser"** → Validation commande (étape 03.3).

**Navigation:**
- **Breadcrumb desktop:** `Boutique Ouaga > Commandes internes > #CMD-2026-038`
- Mobile : back + titre "Commande #CMD-2026-038" + menu ⋮

**On-Page Interactions (storyboard items):**
- **Lecture détail produits** (image, qté, prix unitaire, total)
- **Lecture motif commercial** (texte libre + photos optionnelles)
- **Timeline workflow** (qui a fait quoi, quand)
- **Lien fournisseur suggéré** (info)
- **Boutons sticky** Valider / Refuser
- **Tap photo** → preview plein écran
- **Tap historique** → liste des actions complète

**Contenu clé:**
- Header : n°, statut "À valider par toi", urgence
- Récap : créé par (commercial), date, fournisseur suggéré, montant estimé
- Liste produits demandés (image, nom, qté demandée, prix unitaire, sous-total)
- Card motif : texte du commercial + photos rupture stock
- Timeline workflow visuel (3 étapes)
- Sticky bottom : Valider · Refuser

## States à maquetter

1. **Default M** — commande complète "à valider par toi" avec photo rupture
2. **Workflow expanded M** — timeline complète des 3 étapes avec horodatage
3. **Photo preview M** — image rupture stock plein écran
4. **Default Desktop** — 2 colonnes : produits+motif à gauche, workflow+actions à droite
