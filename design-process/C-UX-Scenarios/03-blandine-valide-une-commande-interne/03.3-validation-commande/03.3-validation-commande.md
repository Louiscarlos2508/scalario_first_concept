# 03.3 — Validation commande interne

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 03: Blandine valide une commande interne |
| **Page Number** | 03.3 |
| **Platform** | Mobile (Android) — version desktop avec breadcrumb |

## Overview

**Page Purpose:** Confirmer la décision finale (Valider ou Refuser) avec un commentaire optionnel (Valider) ou obligatoire (Refuser). Notifier le commercial et la gérante. Tracer dans l'historique.

**Entry Context:** Blandine a lu le détail (03.2) et tape "Valider" ou "Refuser".

**Exit Action:** Tape **"Confirmer la validation"** → toast succès → retour liste 03.1 ✓

**Navigation:**
- Modal bottom sheet sur mobile (par-dessus 03.2)
- Modal centré sur desktop

**On-Page Interactions (storyboard items):**
- **Champ commentaire** (optionnel pour valider, obligatoire pour refuser)
- **Suggestions motifs refus** (chips : Hors budget · Stock OK · Mauvais fournisseur · Autre)
- **Tap "Confirmer"** → impression visuelle de l'action + notif push commercial+gérante
- **Toast succès** "Commande validée · Commercial notifié"
- **Bouton secondaire "Retour"** pour annuler

**Contenu clé:**
- Récap mini : n° commande, montant, créateur
- Icône grosse Valider (vert) ou Refuser (rouge)
- Champ commentaire avec compteur caractères
- Mention "Notification envoyée à : [créateur] + [gérante]"
- CTA primaire pleine largeur

## States à maquetter

1. **Modal Valider M** — bottom sheet vert, commentaire optionnel
2. **Modal Refuser M** — bottom sheet rouge, motif obligatoire avec chips suggestions
3. **Succès Validation M** — écran confirmation pleine page (✓ vert + retour auto)
4. **Default Desktop** — modal centré Valider avec récap + champ commentaire
