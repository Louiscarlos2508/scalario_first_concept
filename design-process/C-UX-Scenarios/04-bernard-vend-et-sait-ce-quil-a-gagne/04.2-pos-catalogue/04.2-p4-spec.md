# 04.2 — POS Catalogue · Phase 4 UX Spec

## Identité de la page
- **Nom** : POS — Catalogue produits
- **Scénario** : 04 — Bernard Vend et Sait Ce Qu'il a Gagné
- **Persona** : Koné Tiéba (vendeur)
- **Plateforme** : Desktop (PC boutique) — plein écran
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre au vendeur de trouver rapidement les produits à vendre et de composer le panier du client.

## Point d'entrée
Session ouverte via PIN (04.1) → arrivée directe sur cette page.

## État mental de l'utilisateur
Présence client devant lui. Veut trouver les produits vite et sans erreur.

## Résultats attendus
- Vendeur sélectionne les produits en quelques secondes
- Panier visible en temps réel
- Alerte stock bas visible sans bloquer la vente

## Layout 2 colonnes

### Gauche — Catalogue
- Top bar sombre persistante : wordmark + "Point de vente" + session active + bouton panier avec compteur
- Barre recherche + filtres par catégorie (chips)
- Grille produits : emoji / nom / catégorie / prix / niveau stock
- États card : normal / in-cart (bordure verte + badge quantité) / stock bas (bordure jaune + ⚠)

### Droite — Mini panier (300px)
- Liste articles en cours avec quantités +/−
- Total dynamique
- CTA "Valider le panier →" → 04.3 POS Panier

## Note prototype
Représentation statique — interactivité réelle dans Flutter.

## Navigation sortante
"Valider le panier" → **04.3 POS Panier**
