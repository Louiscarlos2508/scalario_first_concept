# 04.3 — POS Panier · Phase 4 UX Spec

## Identité de la page
- **Nom** : POS — Panier
- **Scénario** : 04 — Bernard Vend et Sait Ce Qu'il a Gagné
- **Persona** : Koné Tiéba (vendeur)
- **Plateforme** : Desktop (PC boutique)
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre au vendeur de vérifier le panier avant encaissement, ajuster les quantités, et confirmer le total.

## Point d'entrée
"Valider le panier" depuis 04.2 POS Catalogue.

## Layout 2 colonnes

### Gauche — Articles
- Liste détaillée : emoji / nom / prix unitaire / quantité +/− / total ligne / suppression
- Champ note optionnel
- Lien retour catalogue

### Droite — Résumé
- Décomposition ligne par ligne
- Remise (0 FCFA par défaut, modifiable)
- Total block dark (montant en grand)
- Association client optionnelle
- CTA "Encaisser [montant] FCFA →"
- Bouton secondaire "Modifier le panier"

## Navigation
- Retour : ← POS Catalogue (04.2)
- Validation : → POS Paiement (04.4)
