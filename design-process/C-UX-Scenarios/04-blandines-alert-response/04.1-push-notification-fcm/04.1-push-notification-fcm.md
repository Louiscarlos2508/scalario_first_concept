# 04.1 — Push Notification FCM

## Overview

**Page Purpose:** La notification push OS informe Blandine d'une alerte critique avec un résumé immédiatement lisible — tap = deep link direct dans l'app sur la vue alerte.

**Entry Context:** Premier step — départ du scénario. Blandine est hors du magasin, téléphone en poche ou en main.

**Exit Action:** Tap sur la notification → app ouverte directement sur 04.2 Dashboard OWNER Vue Alerte.

**On-Page Interactions:**
- Notification OS Android : icône Scalario + titre + corps + timestamp
- Titre : "⚠️ Stock critique — [Nom article]"
- Corps : "[Quantité] restants — seuil minimum atteint"
- Tap = deep link Flutter → Dashboard OWNER filtré sur l'alerte active
- Pas de boutons d'action inline (Phase 1) — action dans l'app

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Blandine, hors du magasin — domicile, transport, autre marché. En train de faire autre chose quand la notification arrive.

**Mental State (Q4):**
- Hope: Comprendre immédiatement ce qui se passe, reprendre le contrôle à distance
- Worry: Quelque chose de grave est arrivé et elle est trop loin pour agir à temps

**Discovery Method (Q6):** Push FCM reçue automatiquement depuis le backend Scalario — déclenchée par règle JSON (seuil stock atteint). Blandine n'a rien à faire pour la recevoir.
