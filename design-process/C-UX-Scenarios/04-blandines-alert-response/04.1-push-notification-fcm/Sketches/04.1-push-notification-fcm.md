## Annotations — Push FCM

### Canaux Android

```
Configuration FCM Android channels (créés au premier lancement) :

  scalario_alerts    → IMPORTANCE_HIGH   → son + vibration + heads-up
  scalario_sync      → IMPORTANCE_LOW    → silencieux, pas de heads-up
  scalario_messages  → IMPORTANCE_DEFAULT → son sans heads-up
```

### Types d'alertes FCM et routing

| Type alerte | Titre push | Corps push | Deep link route |
|-------------|-----------|-----------|----------------|
| `stock_critical` | "⚠️ Stock critique — [Article]" | "[Quantité] restants · seuil atteint" | /dashboard-owner?type=stock_critical |
| `sale_anomaly` | "⚠️ Vente inhabituelle" | "[Montant] · [Commercial] · contrôle" | /dashboard-owner?type=sale_anomaly |
| `session_close` | "Clôture soumise par [Commercial]" | "Montant : [X] FCFA · Écart : [Y]" | /dashboard-owner?type=session_close |
| `sync_success` | "Synchronisation réussie" | "[N] actions synchronisées" | /dashboard-owner (silencieux) |
| `credit_due` | "Crédit arrivant à échéance" | "[Client] — [Montant] FCFA — [Date]" | /dashboard-owner?type=credit_due |

### Règle silence nocturne

```
22h00 → 07h00 : alertes stock_critical et sale_anomaly en mode silencieux
Exception : si alertes marquées "urgent" dans JSON config tenant → toujours avec son
Configurable par Blandine dans les paramètres (S13 Alert Config)
```
