### Règle hiérarchie AlertBanner — Priorité couleur

```
Règle DS : Une seule AlertBanner normalement.
Exception alerte : max 2 visible simultanément.

Empilement par priorité décroissante :
  1. color-danger-500  (rouge)  — stock_critical / vente_anomaly critique
  2. color-warning-500 (ambre)  — stock_low / crédit_due / session_close
  3. color-primary-500 (bleu)   — info / sync / nouveau user
  4. color-success-500 (vert)   — succès (auto-dismiss 2s)

Border-l épaisseur alerte critique : 4px (vs 3px alertes normales)
```
