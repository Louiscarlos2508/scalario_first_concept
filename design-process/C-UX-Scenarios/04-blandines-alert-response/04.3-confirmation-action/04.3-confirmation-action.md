## Overview

**Page Purpose:** L'action de Blandine est confirmée — le Manager est notifié, l'alerte est marquée "en cours de traitement", Blandine reprend le contrôle à distance.

**Entry Context:** Vient de 04.2 via tap `ActionButton` "Notifier le Manager".

**Exit Action:** `AlertBanner` vert "Manager notifié" (2 sec) → retour Dashboard OWNER — alerte passée en statut "en traitement" ✓

**On-Page Interactions:**
- `AlertBanner` vert "Ibrahim notifié — stock Tomates en cours de traitement"
- Ibrahim reçoit push FCM de son côté → déclenche potentiellement Scenario 05
- `AlertBanner` critique (rouge) remplacée par ambre "En traitement" sur le dashboard
- Blandine peut fermer l'app — action complète
