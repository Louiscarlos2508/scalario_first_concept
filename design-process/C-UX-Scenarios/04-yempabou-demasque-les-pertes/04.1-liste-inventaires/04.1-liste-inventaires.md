## Overview

**Page Purpose:** Lister tous les inventaires (en cours, archivés), permettre d'en lancer un nouveau (complet ou par catégorie/zone), reprendre un inventaire en pause, consulter les anciens résultats.

**Entry Context:** Yempabou ouvre le menu principal → "Inventaires". OU clic depuis le Dashboard tuile "Inventaire de la semaine".

**Exit Action:** Tape **"Nouvel inventaire"** (FAB ou bouton header) → modal/sheet "Périmètre" → choix → étape 04.2 Inventaire en cours.

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Inventaires`
- Mobile : titre "Inventaires" + back

## Sections / Layout

1. **Header** — Titre "Inventaires" + bouton "Nouvel inventaire" (FAB mobile, bouton primaire desktop)
2. **Onglets/Filtre rapide** — `En cours` | `Archivés` | `Tous`
3. **KPI strip (top)** :
   - Dernier inventaire (date + nb écarts + valeur)
   - Prochaine échéance recommandée (ex: "Dimanche prochain")
4. **Liste inventaires** — chaque ligne :
   - Titre (ex: "Inventaire complet du 24/03")
   - Date + heure
   - Périmètre (Tous produits / Catégorie X / Zone Y)
   - Statut (badge) : `Brouillon` / `En cours` / `À valider gérant` / `À valider patron` / `Archivé`
   - Résumé : `12 écarts • -18 500 F`
   - Auteur (qui l'a fait)
   - Tap → ouvre l'inventaire (en cours = reprend, archivé = consulte)
5. **Empty state** — "Aucun inventaire encore. Lancez le premier inventaire de la semaine."

## On-Page Interactions

- **Filtre période** (mois en cours / 3 mois / personnalisé)
- **Recherche** par titre ou date
- **Swipe sur ligne (mobile)** → archive / supprimer brouillon
- **Modal "Nouvel inventaire"** :
  - Périmètre : Tous produits / Une catégorie / Zone (rayon)
  - Optionnel : titre custom
  - Bouton "Démarrer"
