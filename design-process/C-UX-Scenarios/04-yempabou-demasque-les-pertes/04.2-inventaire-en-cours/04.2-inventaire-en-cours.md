## Overview

**Page Purpose:** Saisir produit par produit la quantité réelle comptée. Voir l'écart calculé en live (théorique vs réel). Marquer un produit "compté", reprendre plus tard, scanner code-barre pour aller vite.

**Entry Context:** Yempabou vient de cliquer "Démarrer" sur le modal Périmètre de 04.1.

**Exit Action:** Tape **"Terminer l'inventaire"** (visible une fois ≥1 produit compté) → étape 04.3 Résultat.

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Inventaires > Inventaire #INV-2026-014`
- Mobile : back (= mise en pause auto) + titre "Inventaire en cours" + menu ⋮ (Pause / Annuler)

## Sections / Layout

1. **Header progress** — barre de progression (ex: 87 / 150 produits comptés · 58%) + temps écoulé
2. **Search + Scan** — champ recherche produit + bouton scanner code-barre (icône caméra)
3. **Filtre rapide** — `Tous` | `Restants` | `Comptés` | `Avec écart`
4. **Liste produits** — chaque ligne :
   - Photo + nom produit + catégorie
   - Théorique : ex `24`
   - Champ saisie réel (numérique, gros tap target)
   - Écart calculé en live (gris si non saisi, rouge si négatif, vert si positif, bleu si =0)
   - Coche "compté" si saisi
   - Tap ligne → focus champ saisie + numpad
5. **Sticky bottom** — bouton primaire "Terminer l'inventaire" (désactivé si 0 compté)

## On-Page Interactions

- **Saisie qté réelle** (numpad in-app, pas clavier système — plus rapide)
- **Scan code-barre** → ouvre caméra, détecte EAN, focus produit + saisie
- **Marquer "non trouvé"** (= 0 explicite, badge spécial)
- **Note motif d'écart** sur une ligne (icône 📝 → mini-modal : "Casse / Vol / Erreur livraison / Périmé / Autre")
- **Pause auto** : tout est sauvegardé en local en continu
- **Modal "Terminer ?"** récap rapide : `87 comptés · 63 restants · Voulez-vous vraiment terminer ?`

## États

7. **Default Desktop** — table 2 colonnes (liste à gauche, panneau produit sélectionné à droite)

- Progress = count(qtyReal != null) / total
