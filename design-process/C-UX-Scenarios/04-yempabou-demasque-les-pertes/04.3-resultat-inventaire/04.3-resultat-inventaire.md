## Overview

**Page Purpose:** Présenter le résultat complet d'un inventaire — synthèse globale + détail par produit avec écarts visibles, et permettre la validation gérant → patron. C'est la page "moment aha" de Yempabou.

**Entry Context:** Arrive après la fin de saisie de l'inventaire (étape 04.2). Ou ouverture d'un inventaire archivé depuis 04.1.

**Exit Action principale:** Tape **"Valider et envoyer au patron"** → statut passe à `À valider patron` → notification push patron + retour Liste inventaires. ✓

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Inventaires > [Titre inventaire]`
- Mobile : back + titre "Résultat inventaire"

## Sections / Layout

### 1. Header summary (sticky top)
- Titre inventaire + date + auteur
- Statut badge (En attente validation gérant / patron / Validé / Archivé)

### 2. KPI synthèse (3-4 cards visibles en 5s)

| KPI | Valeur | Visuel |
|---|---|---|
| **Total produits comptés** | 150 / 150 | progress 100% |
| **Écarts détectés** | 15 produits | badge |
| **Valeur écarts négatifs** | **-18 500 F** | rouge gros |
| **Valeur écarts positifs** | +2 100 F | vert |

### 3. Top 5 pertes (mise en évidence)
Liste compacte des 5 produits avec le plus gros écart négatif :
- Photo + nom produit
- Théorique : 24 — Réel : 18 — Écart : **-6** (rouge)
- Valeur perdue : -3 600 F
- Tap → fiche produit + historique mouvements

### 4. Détail complet par produit (collapsible)
Tableau / liste filtrable :
- Filtre : `Tous` / `Avec écart` / `Négatifs uniquement` / `Positifs uniquement`
- Tri : par valeur écart / par catégorie / alphabétique
- Colonnes : Produit | Théorique | Réel | Écart | Valeur | Motif
- Mise en évidence visuelle : ligne rouge si négatif, verte si positif

### 5. Bloc validation
- Si statut `À valider gérant` (vue gérant) : bouton "Valider et envoyer au patron"
- Si statut `À valider patron` (vue patron) : boutons "Valider" / "Refuser et redemander"
- Si validé : badge + horodatage + signataires
- Champ commentaire optionnel

### 6. Actions secondaires
- **Exporter PDF** (pour partage WhatsApp)
- **Exporter Excel/CSV** (pour comptable)
- **Ajuster le stock système** (case cochée par défaut à validation)

## On-Page Interactions

- Filtre liste produits (Tous/Écart/Négatifs/Positifs)
- Tri liste produits
- Tap produit → drawer/modal détail produit + mouvements stock récents
- Édition motif d'écart en ligne (avant validation)
- Modal "Refuser" → champ motif obligatoire

## Données affichées

- Inventory complet avec ses InventoryItems
- Pour chaque item : product, qté théorique, qté réelle, écart calculé, valeur unitaire, valeur écart, motif
- Calculs agrégés (totaux, écarts globaux)

## États

- **Brouillon en cours** : non accessible (l'utilisateur est en 04.2)
- **À valider gérant** : vue gérant avec action validation
- **À valider patron** : vue patron avec action validation/refus
- **Validé / Archivé** : lecture seule + boutons export
- **Refusé** : motif visible, gérant peut reprendre l'inventaire

## Pourquoi cette page est critique (UX)

- C'est LE moment où Yempabou voit la valeur de Scalario
- L'écart négatif total doit être **le chiffre le plus visible** de l'écran (gros, rouge)
- Le top 5 doit être en haut, pas caché dans la liste
- La validation doit être 1 tap, pas un parcours
