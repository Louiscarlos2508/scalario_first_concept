# 05.2 — Saisie Livraison

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 05: Ibrahim's Delivery Validation |
| **Step** | 05.2 |
| **Platform** | Mobile Android mid-range — debout, une main |

## Overview

**Page Purpose:** Ibrahim saisit les quantités réellement reçues pour chaque article — le système compare automatiquement avec les quantités attendues (depuis JSON).

**Entry Context:** Vient de 05.1 via tap `ActionButton` "Réception livraison".

**Exit Action:** Tap "Confirmer la saisie" → step 05.3.

**On-Page Interactions:**
- `FormWidget` — liste articles attendus depuis JSON commande
- Par article : quantité attendue (référence) + `QuantityControl` saisie reçue
- Écart calculé en temps réel par article (vert/ambre/rouge)
- Touch targets 48dp — usage une main debout

---

## Composants BDUI

| Composant | État | Notes |
|-----------|------|-------|
| `FormWidget` | liste articles | Articles depuis JSON — nom Inter, quantité attendue Roboto Mono |
| `QuantityControl` | saisie reçue | +/- ou saisie directe — 48dp touch target |
| `KPICard` | écart par article | Vert (ok) / Ambre (manque mineur) / Rouge (manque significatif) |
| `ActionButton` | "Confirmer" | Actif dès tous les articles saisis |
