### Règles touch targets (usage une main)

```
QuantityControl − et + : 48dp × 48dp minimum
  → évite erreur de tap quand Ibrahim est debout, marchandise dans l'autre main
Champ saisie directe : height 48dp minimum
Article card : h=88dp (expanded) / h=44dp (condensé)
CTA Confirmer : height 48dp (standard) — au bas de l'écran, accessible pouce
```

### Code couleur feedback en temps réel

```
Quantité non saisie    → card bg color-white     · nom color-neutral-700
Reçu = attendu (100%) → card bg color-success-50 · préfixe ✓ color-success-700
Reçu < attendu (≥80%) → card bg color-warning-50 · préfixe ⚠ color-warning-700
Reçu < attendu (<80%) → card bg color-danger-50  · préfixe ✕ color-danger-700
Reçu = 0 explicite    → card bg color-danger-50  · note obligatoire activée

Seuils configurables JSON (ex: mineur < 20% = ambre, majeur ≥ 20% = rouge)
```
