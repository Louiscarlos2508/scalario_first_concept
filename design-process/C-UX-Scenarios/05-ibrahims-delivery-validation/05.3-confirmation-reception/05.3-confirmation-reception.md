# 05.3 — Confirmation Réception

## Page Metadata

| Property | Value |

## Overview

**Page Purpose:** Ibrahim voit le récap complet (attendu vs reçu par article), valide — le stock Drift est mis à jour automatiquement et Blandine voit les nouvelles quantités sur son dashboard.

**Entry Context:** Vient de 05.2 via tap "Confirmer la saisie".

**Exit Action:** Tap "Valider la réception" → stock mis à jour, `AlertBanner` vert "Livraison enregistrée" → retour Dashboard MANAGER ✓

**On-Page Interactions:**
- `ConfirmationDialog` — récap par article : attendu / reçu / écart (Roboto Mono)
- Total livraison en bas (valeur stock ajoutée)
- `ActionButton` "Valider la réception" — primaire
- Post-validation : stock Drift mis à jour → Blandine voit nouvelles quantités sur son dashboard
