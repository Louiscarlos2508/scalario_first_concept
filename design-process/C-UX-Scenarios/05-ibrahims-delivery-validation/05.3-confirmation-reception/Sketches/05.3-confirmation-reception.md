### Règle CTA selon gravité écarts

```
0 écart ou écarts mineurs (< seuil JSON) :
  "Valider la réception" → bg #FFCC00 color-neutral-900

Manque significatif (article = 0 ou > seuil JSON) :
  "Valider avec le manque documenté" → bg color-danger-500 color-white
  Logique : couleur rouge = conséquence visible → Ibrahim réfléchit avant de valider
            Mais jamais bloquant — Ibrahim a le droit de valider quand même
```

### Impact sur alertes stock (résolution automatique)

```
Après validation livraison :
  Pour chaque article reçu :
    IF (stock_actuel + quantité_reçue) >= seuil_alerte :
      alerte.status = "resolved"
      push Blandine "Stock [article] rétabli"

  Si alerte stock_critical était active → auto-résolue → S04.3 alerte ambre disparaît
  Dashboard Blandine : KPICard "Stock KOs" count décrémenté
```
