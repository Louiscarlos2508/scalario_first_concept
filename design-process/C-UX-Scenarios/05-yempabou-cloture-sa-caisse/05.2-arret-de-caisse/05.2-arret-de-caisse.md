## Overview
**Page Purpose:** Saisir le montant réel compté par mode de paiement, voir l'écart calculé en live (théorique vs réel), justifier les écarts, transmettre l'arrêt au patron.

**Entry Context:** Yempabou vient de taper "Clôturer la caisse" depuis 05.1.

**Exit Action:** Tape **"Valider et envoyer"** → étape 05.3 Historique arrêts (confirmation).

**Navigation:**
- Mobile : back + titre "Arrêt de caisse"
- Desktop : breadcrumb `Boutique > Caisse > Session #SES-014 > Arrêt`

## Sections / Layout

1. **Header session** — n° session, caissier, durée, fond initial
2. **KPI hero — Écart total** — gros chiffre central (vert si OK, rouge si négatif)
3. **Saisie par mode de paiement** — pour chaque mode (Cash, Wave, OM, Crédit) :
   - Théorique (calculé) — gris
   - Réel — input numérique
   - Écart calculé en live (badge couleur)
4. **Détail Cash** — coupures (10000/5000/2000/1000/500/200/100/50) — saisie pavé tactile
5. **Motif écart** — chips si écart ≠ 0 (Erreur de rendu / Pourboire / Vol présumé / Autre)
6. **Sticky bottom** — bouton primaire "Valider et envoyer au patron"
