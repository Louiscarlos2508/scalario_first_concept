## Overview
**Page Purpose:** Confirmer visuellement l'arrêt qui vient d'être créé, et lister les arrêts récents avec leurs statuts (en attente patron / validé / refusé).

**Entry Context:** Arrive après validation depuis 05.2 OU depuis menu "Caisse > Historique".

**Exit Action:** Retour menu principal OU tap sur arrêt → fiche détail.

**Navigation:**
- Mobile : back + titre "Arrêts de caisse"
- Desktop : breadcrumb `Boutique > Caisse > Historique`

## Sections / Layout

1. **Banner succès** (si juste validé) — ✓ vert "Arrêt envoyé au patron · #ARR-2026-098"
2. **Filtres tabs** — `Tous` | `En attente` | `Validés` | `Refusés`
3. **KPI strip** — Total semaine ventes, Écarts cumulés, Taux de validation
4. **Liste arrêts** — chaque ligne :
   - Date + caissier
   - Total ventes + écart (couleur)
   - Statut badge
   - Tap → drawer détail
5. **Empty / Loading**
