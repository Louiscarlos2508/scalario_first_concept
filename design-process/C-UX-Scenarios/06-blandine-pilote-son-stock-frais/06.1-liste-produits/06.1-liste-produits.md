## Overview

**Page Purpose:** Vue catalogue complète — liste de TOUS les produits, filtrable par catégorie/statut/fraîcheur, avec accès rapide aux fiches et à la création.

**Entry Context:** Menu principal → "Produits". OU depuis Dashboard tuile "Stock bas" (page filtrée).

**Exit Action principale:** Tape **"+ Nouveau produit"** (FAB mobile, bouton header desktop) → Création produit (06.3).
**Exit Action secondaire:** Tap sur un produit → Fiche produit (06.2).

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Produits`
- Mobile : titre "Produits" + recherche

## Sections / Layout

### 1. Header sticky
- Titre + bouton "+ Nouveau"
- Barre de recherche (autocomplete sur nom + code-barres)
- Filtres rapides (chips horizontales) : `Tous` | `En rupture` | `Stock bas` | `Fraîcheur rouge` | `Périmé`

### 2. Sidebar / Drawer catégories (desktop)
Arborescence catégories pour filtrer (Fruits, Légumes, Épices...).

### 3. Liste produits (cards ou rows selon device)
Chaque ligne :
- Photo produit (placeholder si absent)
- Nom + code-barres
- Catégorie (badge)
- Prix détail (+ prix gros si applicable)
- Stock actuel + indicateur couleur
- Badge fraîcheur (vert/orange/rouge) si périssable
- Badge alerte (icône warning si stock bas)
- Tap → Fiche produit

### 4. Tri & vue
- Tri : Nom / Stock / Valeur / Dernière vente / Plus vendus
- Toggle vue : grille / liste

### 5. Stats footer (optionnel desktop)
- Nb produits total
- Valeur stock total
- Nb alertes

## On-Page Interactions

- **Recherche live** (debounced)
- **Filtre catégorie** (multi-select)
- **Filtre statut** (chips)
- **Filtre fraîcheur**
- **Tri**
- **Sélection multiple** (long press) → actions batch (changer prix, archiver, exporter)
- **Pull-to-refresh**
- **Scan code-barres** (FAB secondaire) → trouve le produit + ouvre sa fiche

## Différences vs CategoriesScreen actuel

- **CategoriesScreen est centré sur les catégories** — il faut une **liste produits unifiée** avec catégories en filtre, pas en arborescence principale
- **Recherche live + filtres rapides** absents dans l'actuel
- **Code couleur fraîcheur** sur chaque ligne (différenciateur Blandine)
- **Vue mobile en cards photo-first**, vue desktop en table dense
- **Action "Nouveau produit" affordante** (FAB ou bouton primaire)

## Données affichées

- Tous les Products du tenant
- Pour chaque : id, photo, nom, code-barres, categoryId, prixDétail, prixGros, stock actuel, fraîcheurStatus, alerts, lastSoldAt
