## Overview
**Page Purpose:** Vue détaillée d'un produit — photo, infos, prix, stock courant, fraîcheur, frotte, vrac, derniers mouvements, alertes actives.

**Entry Context:** Tap sur un produit depuis 06.1 OU depuis dashboard alertes OU depuis mouvements stock.

**Exit Action:** Tap "Éditer" → 06.3 OU "Voir tous les mouvements" → 06.5.

**Navigation:**
- Mobile : back + titre nom + menu ⋮ (Éditer / Archiver / Partager)
- Desktop : breadcrumb `Boutique > Produits > [Nom]`

## Sections / Layout
1. **Hero produit** — Photo XL + nom + catégorie + badges (Stock bas / Fraîcheur rouge / Vrac)
2. **KPI strip** — Stock actuel · Valeur stock · Vendus 30j · Marge moyenne
3. **Bloc Prix** — Prix achat / Détail / Gros (+ qté min) / Marge calculée
4. **Bloc Stock & seuils** — Quantité actuelle, seuil alerte, unité, jours d'autonomie
5. **Bloc Fraîcheur** (si périssable) — Durée de vie, prochaine péremption, badge couleur
6. **Bloc Frotte** (si activé) — Taux %, frotte cumulée du mois
7. **Bloc Vrac→sachet** (si activé) — Conversion, prix unité de vente
8. **Derniers mouvements** (5) — Lien vers 06.5
9. **Sticky bottom mobile** — boutons Éditer / Mouvements / Imprimer

## États
1. Default M — produit frais avec alerte stock bas
2. Vrac M — produit vrac→sachet avec conversion visible
3. Périmé M — bandeau rouge "À retirer du rayon"
4. Default Desktop — 2 col (hero+blocs gauche, mouvements droite)
