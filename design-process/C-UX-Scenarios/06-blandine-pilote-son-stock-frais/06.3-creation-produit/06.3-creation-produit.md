## Overview

**Page Purpose:** Formulaire complet pour créer ou éditer un produit avec toutes ses spécificités Phase 1 : infos de base, prix détail/gros, frotte, conversion vrac→sachet, fraîcheur/péremption, photo.

**Entry Context:** Depuis Liste produits (06.1) → tap "+ Nouveau". OU depuis Fiche produit (06.2) → tap "Éditer".

**Exit Action:** Tape **"Enregistrer"** → retour Fiche produit (en mode lecture) avec toast "Produit créé/modifié". OU "Annuler" → retour liste.

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Produits > Nouveau produit` (ou `> [Nom] > Éditer`)
- Mobile : back + titre + action sticky bottom

## Sections / Layout (formulaire en sections collapsibles ou tabs)

### 1. Infos générales
- Photo (upload + crop) — placeholder caméra/galerie
- Nom (obligatoire)
- Code-barres (scanner ou saisie)
- Catégorie (dropdown + créer nouvelle)
- Description (optionnel)

### 2. Prix & vente
- Prix d'achat (HT)
- Prix de vente détail (obligatoire)
- Prix de vente gros (optionnel + qté minimum gros)
- Marge calculée auto (affichage)

### 3. Stock
- Quantité initiale
- Seuil alerte stock bas
- Unité de base (pièce, kg, sac, litre...)

### 4. Périssable & fraîcheur (toggle on/off, visible si périssable)
- Durée de vie estimée (jours)
- Délai alerte fraîcheur (jours avant péremption → rouge)
- Date de péremption initiale (optionnel)

### 5. Frotte (toggle on/off)
- Taux de frotte estimé (%)
- Mode de calcul : appliqué automatiquement à chaque réception

### 6. Vrac → sachet (toggle on/off)
- Unité d'achat (ex: sac de 25kg)
- Unité de vente (ex: sachet de 100g)
- Ratio de conversion auto-calculé
- Prix par unité de vente auto-calculé

### 7. Fournisseur principal (optionnel)
- Dropdown fournisseurs existants + créer nouveau
- Référence chez le fournisseur

## On-Page Interactions

- **Validation live** (champs obligatoires, formats prix)
- **Calcul auto marge** quand prix achat + prix vente saisis
- **Calcul auto ratio vrac→sachet**
- **Toggle sections** périssable/frotte/vrac (cachées si pas applicable)
- **Scanner code-barres** → si code existe déjà → message "Produit déjà existant, voulez-vous l'éditer ?"
- **Sticky bottom** : "Enregistrer" + "Enregistrer et créer un autre" (mode batch)

## Validation

- Nom obligatoire
- Prix vente détail obligatoire
- Si vrac→sachet activé : unités + ratio obligatoires
- Si périssable : durée de vie obligatoire

## États

- **Création** : tous champs vides, défauts intelligents (catégorie pré-sélectionnée si vient d'un filtre)
- **Édition** : champs pré-remplis, bouton "Enregistrer" devient "Mettre à jour"
- **Erreur sync** : sauvegarde locale, indicateur "À synchroniser"

## Pourquoi cette page est critique

- Toutes les fonctionnalités différenciantes Phase 1 (frotte, vrac→sachet, fraîcheur) passent par ce formulaire
- Doit être ergonomique sur mobile (Blandine ajoute des produits depuis Dakar)
- Doit gérer la complexité (toggles) sans submerger un patron qui crée son 1er produit
