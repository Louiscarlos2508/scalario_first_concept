## Overview
**Page Purpose:** Centraliser tous les produits nécessitant une attention — stock bas, rupture, fraîcheur orange/rouge, périmés. Permettre une action rapide (réappro, retrait, ajustement).

**Entry Context:** Menu "Alertes" OU dashboard tuile "X alertes actives" OU notification push.

**Exit Action:** Tap sur alerte → fiche produit OU action rapide "Réapprovisionner" / "Retirer".

**Navigation:**
- Mobile : back + titre "Alertes stock"
- Desktop : breadcrumb `Boutique > Stock > Alertes`

## Sections / Layout
1. **KPI strip** — Total alertes, Rupture, Stock bas, Fraîcheur, Périmés
2. **Tabs** — `Toutes` | `Rupture` | `Stock bas` | `Fraîcheur` | `Périmés`
3. **Liste alertes** — chaque ligne :
   - Photo + nom produit
   - Type alerte (icône + couleur)
   - Détail (ex: "Stock 2/15 · seuil atteint", "Périme dans 2j", "Rupture depuis hier")
   - Suggestion action (ex: "Réappro 50 unités")
   - Boutons quick action
4. **Empty state** — "✓ Aucune alerte, tout est OK"
