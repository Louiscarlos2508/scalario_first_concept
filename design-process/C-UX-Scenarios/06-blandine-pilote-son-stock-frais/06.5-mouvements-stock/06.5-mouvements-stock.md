## Overview

**Page Purpose:** Historique de tous les mouvements de stock — entrées (réceptions), sorties (ventes, frotte, casse, expirés), ajustements (inventaire), transferts. Permet de tracer l'origine de tout écart.

**Entry Context:** Depuis Fiche produit (06.2) → tap "Voir mouvements". OU menu Stock → "Mouvements". OU depuis Dashboard → tuile "Mouvements suspects".

**Exit Action:** Tap sur une ligne mouvement → drawer/page détail (vente liée, inventaire lié, etc.).

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Stock > Mouvements` (ou `> Produits > [Nom] > Mouvements`)
- Mobile : back + titre

## Sections / Layout

### 1. Filtres header
- **Période** : Aujourd'hui / 7j / 30j / Custom
- **Type de mouvement** (chips multi-select) : `Entrée` | `Vente` | `Frotte` | `Casse` | `Expiré` | `Inventaire ±` | `Transfert`
- **Produit** (dropdown / recherche) — pré-rempli si on vient d'une fiche produit
- **Auteur** (qui a fait l'opération)

### 2. KPI strip (top)
- Total entrées (qté + valeur)
- Total sorties (qté + valeur)
- Solde net période
- Nb mouvements

### 3. Liste chronologique des mouvements
Chaque ligne :
- Date + heure
- Icône + couleur selon type (vert entrée, rouge sortie/frotte/casse, bleu ajustement)
- Nom produit + qté (avec signe + ou -)
- Source : "Vente #1234" / "Réception fournisseur X" / "Inventaire du 24/03" / "Frotte auto"
- Auteur (avatar)
- Valeur (calculée)
- Tap → détail

### 4. Vue groupée (toggle)
- Par jour (default)
- Par produit
- Par type de mouvement

## On-Page Interactions

- **Filtres** (période, type, produit, auteur)
- **Tri** (récent / ancien / qté / valeur)
- **Export CSV/Excel** (bouton header)
- **Tap ligne** → drawer détail
- **Recherche** dans la liste
- **Pagination** (charge plus si liste longue)

## Différences vs StockViewPage actuel

- **StockViewPage est une vue stock courante** — recadrer en **historique des mouvements**
- **Ajouter filtres par type de mouvement** (essentiel pour traquer la frotte/casse)
- **Code couleur par type** (visuel rapide)
- **KPI strip** entrées/sorties pour synthèse
- **Lien depuis chaque ligne vers la source** (vente, inventaire, réception)
- **Vue groupable** par produit/type/jour

## États

- **Aucun mouvement sur la période** → empty state "Aucun mouvement sur cette période"
- **Beaucoup de mouvements** → pagination ou virtualisation
- **Filtre actif** → badge filtres actifs en haut

## Pourquoi cette page est critique

- C'est l'outil d'investigation pour Yempabou (où est passée la marchandise ?)
- Et l'outil de monitoring pour Blandine (à distance, voir ce qui se passe)
- Doit permettre de remonter facilement de "écart inventaire" à "vente suspecte" ou "frotte non déclarée"
