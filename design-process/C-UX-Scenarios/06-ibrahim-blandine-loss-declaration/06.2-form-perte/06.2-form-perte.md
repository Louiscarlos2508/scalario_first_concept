# 06.2 — FormWidget Perte

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 06: Ibrahim & Blandine's Loss Declaration |
| **Step** | 06.2 |
| **Platform** | Mobile Android mid-range — debout, une main possible |

## Overview

**Page Purpose:** Ibrahim saisit les détails de la perte — article concerné, quantité, nature (avarié / casse / vol / autre), note contextuelle optionnelle.

**Entry Context:** Vient de 06.1 via tap `ActionButton` "Déclarer une perte".

**Exit Action:** Tap "Soumettre la déclaration" → step 06.3.

**On-Page Interactions:**
- `FormWidget` — sélection article (depuis JSON stock)
- `QuantityControl` — quantité perdue
- Sélecteur nature perte : avarié / casse / vol / autre (chips ou dropdown JSON)
- Champ note optionnel — contexte libre (Ibrahim explique sans accusation)
- `ActionButton` "Soumettre" — actif dès article + quantité + nature saisis
