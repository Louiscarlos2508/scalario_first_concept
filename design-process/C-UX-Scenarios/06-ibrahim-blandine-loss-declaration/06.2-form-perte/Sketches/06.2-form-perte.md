# Sketch Hi-Fi — 06.2 FormWidget Perte

> Formulaire de déclaration de perte.
> 4 champs : article · quantité · nature · note (optionnelle sauf "vol").
> ChipSelector nature : Avarié / Casse / Vol / Autre.
> "Vol" → note obligatoire (protection Ibrahim + traçabilité Blandine).
> Quantité bloquée au stock disponible (pas de perte fictive).

|---------|----------|------|------|
| AppBar titre | `font-page-title` | Inter | 16sp 600 |
| Section label | `text-title` | Inter | 18sp 600 |

| Quantité saisie | — | Roboto Mono | 18sp 600 |

| Note placeholder | `text-body` | Inter | 14sp 400 color-neutral-400 |

### Règles ChipSelector "Nature perte"

```
Avarié → bg #FFCC00 · color-neutral-900 · note optionnelle
Casse  → bg #FFCC00 · color-neutral-900 · note optionnelle
Autre  → bg #FFCC00 · color-neutral-900 · note optionnelle
Vol    → bg color-danger-500 · color-white · note OBLIGATOIRE
         + AlertBanner warning contextuel
         + CTA désactivé tant que note vide
```
