# 06.3 — Confirmation Déclaration

## Page Metadata

| Property | Value |

## Overview

**Page Purpose:** Ibrahim voit le récap de sa déclaration, confirme — la perte est enregistrée, le stock mis à jour, et Blandine reçoit une notification push discrète (pas alarmiste).

**Entry Context:** Vient de 06.2 via tap "Soumettre la déclaration".

**Exit Action:** Tap "Confirmer" → perte enregistrée en DB Drift, Blandine notifiée, `AlertBanner` vert "Perte enregistrée" → retour Dashboard MANAGER ✓

**On-Page Interactions:**
- `ConfirmationDialog` — récap : article / quantité / nature / note / horodatage
- Valeur perte estimée (quantité × prix unitaire JSON) — Roboto Mono
- `ActionButton` "Confirmer" — primaire
- Post-confirmation : stock Drift mis à jour, push FCM discret à Blandine
