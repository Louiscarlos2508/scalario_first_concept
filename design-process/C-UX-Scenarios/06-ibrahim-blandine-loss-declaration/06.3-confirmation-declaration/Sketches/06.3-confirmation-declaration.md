### Règle CTA couleur selon nature perte

```
Avarié / Casse / Autre : bg #FFCC00 · color-neutral-900 (standard)
Vol                    : bg color-warning-500 · color-white (sérieux)

Logique : Ibrahim voit la gravité par la couleur du bouton
          Sans jamais bloquer l'acte — il a le droit de valider dans tous les cas
```

### Impact alerte stock post-perte

```
Après confirmation :
  stock_après = stock_avant − quantité_perdue
  IF stock_après < seuil_alerte :
    → alerte stock_critical créée
    → push Blandine "⚠ Stock critique suite à perte" (si pas déjà active)
    → Dashboard Blandine : KPICard "Stock KOs" incrémenté

Exemple : Stock Tomates 27 kg − 2 kg = 25 kg · seuil = 5 kg → OK
          Stock Tomates 6 kg − 2 kg = 4 kg · seuil = 5 kg → alerte
```
