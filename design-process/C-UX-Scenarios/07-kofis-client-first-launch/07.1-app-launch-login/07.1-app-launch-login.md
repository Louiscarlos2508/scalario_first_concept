# 07.1 — App Launch — Login

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 07: Kofi's Client First Launch |
| **Step** | 07.1 |
| **Platform** | Mobile Android mid-range — premier lancement |

## Overview

**Page Purpose:** L'app se lance pour la première fois — Splash → Login username (ou numéro de téléphone) + mot de passe. Auth réussie → profil complet chargé depuis le backend (tenant, département, rôle, permissions, dashboard JSON) → mis en cache Drift pour usage offline.

**Entry Context:** Premier step — premier lancement absolu. Compte créé et vérifié par Kofi lors du onboarding tenant (KYC entreprise + vérification user à la création du compte).

**Exit Action:** Auth réussie → profil identité complet chargé → step 07.2 Dashboard Rôle.

**On-Page Interactions:**
- `SplashScreen` — logo Sc monogramme, fond `#121212`, 2 sec
- `LoginWidget` — champ username (ou numéro téléphone) + mot de passe
- Auth réussie → fetch profil user depuis backend : tenant / département / rôle / permissions / layout JSON → cache Drift
- `ActionButton` "Se connecter" — primaire

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Nouvel employé, au magasin, premier jour. APK installé par Kofi. Peut être nerveux — veut faire bonne impression.

**Mental State (Q4):**
- Hope: Démarrer rapidement, montrer qu'il est capable — pas de formation longue
- Worry: Bloquer dès le premier écran, devoir appeler Kofi ou son patron

**Discovery Method (Q6):** Kofi a installé l'APK et fourni le numéro + PIN de l'employé. Premier tap sur l'icône Scalario depuis l'écran d'accueil Android.
