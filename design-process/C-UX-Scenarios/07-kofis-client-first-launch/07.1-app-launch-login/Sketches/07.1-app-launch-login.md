> Premier lancement absolu — APK installé par Kofi (intégrateur).

### Différences S07.1 (first run) vs S01.1 (re-auth)

```
S07.1 — Premier lancement :
  Username + Password · pas de biométrie · pas de PIN
  ProfileLoader → chargement complet depuis backend
  Offline → bloquant (premier lancement = réseau requis)
  OnboardingCard visible sur Dashboard (S07.2)

S01.1 — Re-authentification (session expirée) :
  Biométrie ou PIN · username pré-rempli (connu Drift)
  Profil depuis cache Drift · login silencieux
  Offline → OK si profil en cache
  Pas d'OnboardingCard
```
