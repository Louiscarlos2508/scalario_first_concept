# 07.2 — Dashboard Rôle — First Run

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 07: Kofi's Client First Launch |
| **Step** | 07.3 |
| **Platform** | Mobile Android mid-range |

## Overview

**Page Purpose:** Le dashboard du rôle s'affiche — `ActionButton` primaire évident above the fold. L'employé comprend son action principale sans instruction. `OnboardingCard` contextuel optionnel, non bloquant.

**Entry Context:** Vient de 07.2 sélection rôle (ou direct depuis 07.1 si mono-rôle). Premier affichage du dashboard pour cet employé.

**Exit Action:** Employé tape l'`ActionButton` primaire de son rôle → commence à travailler ✓

**On-Page Interactions:**
- `ActionButton` primaire rôle — "Nouvelle vente" (COMMERCIAL) / "Réception livraison" (MANAGER) / Dashboard KPIs (OWNER)
- `OnboardingCard` — "Voici ton action principale" — contextuel, dismissable, non bloquant
- `BottomNavigationBar` — tabs rôle configurés par JSON
- État "vide" géré — données à zéro mais pas d'erreur, `EmptyState` engageant
