# Sketch Hi-Fi — 07.2 Dashboard Rôle — First Run

> Premier affichage du dashboard après login réussi.
> OnboardingCard contextuel — non bloquant, dismissable, n'apparaît qu'une fois.
> CTA primaire above the fold — action principale du rôle évidente.
> EmptyState engageant si pas de données (nouveau tenant, premier jour).
> L'app fonctionne dès le premier tap — pas de setup obligatoire.

### OnboardingCard — règles complètes

```
Déclencheur : first_run_onboarding_shown == false (Drift)
Durée d'affichage : jusqu'au tap [× Compris] ou 30s auto-dismiss
Persistance dismiss : flag = true Drift → permanent
Contenu : JSON config rôle — label CTA + phrase d'introduction

Exemple COMMERCIAL :
  "Appuie sur 'Nouvelle vente' pour enregistrer une vente."
Exemple MANAGER :
  "Appuie sur 'Réception livraison' quand tu reçois des marchandises."
Exemple OWNER (S01.2) :
  "Voici ton tableau de bord. Les KPIs se mettent à jour en temps réel."
```
