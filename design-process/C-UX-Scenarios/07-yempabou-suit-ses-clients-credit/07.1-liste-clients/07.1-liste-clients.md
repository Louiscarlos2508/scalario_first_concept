# 07.1 — Liste clients

## Overview
**Page Purpose:** Lister tous les clients de la boutique avec recherche rapide, tri par solde dû ou activité, badges visuels pour les débiteurs.

**Entry Context:** Menu "Clients" OU depuis dashboard tuile "X clients à relancer" OU bouton "Sélectionner client" depuis POS.

**Exit Action:** Tap sur un client → 07.2 Fiche client OU bouton "+ Nouveau client".

**Navigation:**
- Mobile : back + titre "Clients"
- Desktop : breadcrumb `Boutique > Clients`

## Sections / Layout
1. **KPI strip** — Total clients · Débiteurs · Solde dû total · Nouveaux 30j
2. **Search bar** — recherche par nom / téléphone
3. **Tabs / chips tri** — `Tous` | `À crédit` | `Récents` | `VIP`
4. **Liste clients** — chaque ligne :
   - Avatar/initiales (couleur stable)
   - Nom + téléphone
   - Solde dû (rouge si > 0, vert "À jour" si 0)
   - Dernière visite
   - Tag (VIP, fidèle, à risque)
5. **FAB +** — créer nouveau client
6. **Empty state** — "Aucun client enregistré"

## États
1. Default M — 8 clients dont 4 débiteurs
2. Tab À crédit M — uniquement les débiteurs
3. Recherche M — autocomplete "you"
4. Empty M
5. Default Desktop — table avec colonnes nom/tel/CA total/solde dû/dernière visite
