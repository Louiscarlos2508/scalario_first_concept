# 08.1 — Réseau Coupé — App Continue

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 08: Blandine's Offline Day |
| **Step** | 08.1 |
| **Platform** | Mobile Android mid-range — terrain UEMOA |

## Overview

**Page Purpose:** Le réseau coupe pendant l'utilisation — l'app détecte la coupure, affiche un signal discret et non-alarmiste, continue de fonctionner normalement depuis Drift local.

**Entry Context:** Premier step — l'utilisateur est déjà dans l'app (n'importe quel état actif). Le réseau coupe.

**Exit Action:** L'utilisateur poursuit son action normalement → step 08.2.

**On-Page Interactions:**
- `SyncStatusBar` passe de "synced" à "offline" — changement discret, non bloquant
- `AlertBanner` info (bleu ou neutre) — "Hors ligne — tes données sont sauvegardées" — 3 sec puis dismiss
- Aucun modal bloquant, aucune erreur rouge — l'app reste utilisable
- Toutes les données Drift locales restent accessibles — zéro skeleton screen

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Blandine / Commercial / Ibrahim — au marché ou en déplacement. App ouverte et en cours d'utilisation quand le réseau coupe.

**Mental State (Q4):**
- Hope: Continuer à travailler sans interruption — rien n'est perdu
- Worry: Que l'app bloque devant le client — perdre une vente, perdre la face

**Discovery Method (Q6):** L'utilisateur ne "découvre" pas — il est déjà dans l'app. Le réseau coupe, le `SyncStatusBar` change d'état. C'est le seul signal.
