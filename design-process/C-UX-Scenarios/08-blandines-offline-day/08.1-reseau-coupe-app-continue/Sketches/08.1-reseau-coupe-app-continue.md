# Sketch Hi-Fi — 08.1 Réseau Coupé — App Continue

> Le réseau coupe pendant l'utilisation normale.
> L'app détecte la coupure — signal discret, non bloquant.
> L'utilisateur continue à travailler — zéro interruption.
> Drift local = source de vérité — toutes les données accessibles.
> Principe : P3 — offline-first absolu, aucun écran bloqué.

## Annotations — Réseau Coupé

### États SyncStatusBar complets

| État réseau | Icône | Bg | Label |
|-------------|-------|----|-------|
| Nominal | ● | color-success-100 | "Synchronisé · il y a Xmin" |
| Sync en cours | [↻] spinner | color-neutral-50 | "Sync en cours..." |
| Signal faible | [↻] spinner | color-warning-100 | "Sync en cours... · connexion instable" |
| Offline réseau | 🔌 | color-warning-100 | "Hors ligne · Dernière sync : HH:MM" |
| Backend down | ⚠ | color-warning-100 | "Serveur indisponible · Drift local actif" |
| Offline longue durée | 🔌 | color-warning-100 | "Hors ligne depuis Xh" + AlertBanner persistent |

### Principe P3 — Non-interruption absolue

```
INTERDIT en mode offline :
  ✕ Modal bloquant "Vous êtes hors ligne"
  ✕ Skeleton screens
  ✕ Erreurs rouges sur les données locales
  ✕ CTAs désactivés pour cause d'offline
  ✕ Messages "Fonctionnalité indisponible hors ligne"

AUTORISÉ en mode offline :
  ✓ SyncStatusBar ambre (discret, non bloquant)
  ✓ AlertBanner info (3s auto-dismiss, non bloquant)
  ✓ Badge _local_ sur données non syncées
  ✓ Badge ↻ sur actions en queue
  ✓ Horodatage "Dernière sync : HH:MM" dans SyncStatusBar
```
