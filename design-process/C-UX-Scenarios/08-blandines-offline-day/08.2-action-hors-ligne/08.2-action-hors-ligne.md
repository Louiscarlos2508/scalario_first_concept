# 08.2 — Action Hors Ligne Complétée

## Page Metadata

| Property | Value |
|----------|-------|

| **Step** | 08.2 |

## Overview

**Page Purpose:** L'utilisateur complète son action normalement — vente enregistrée, clôture saisie, livraison documentée — tout est sauvegardé dans Drift local. Zéro différence visible avec le mode en ligne.

**Entry Context:** Vient de 08.1 — réseau offline, `SyncStatusBar` offline visible. L'utilisateur continue son workflow.

**Exit Action:** Action enregistrée dans Drift local → mise en queue sync → step 08.3 quand le réseau revient.

**On-Page Interactions:**
- Workflow identique au mode en ligne — formulaires, validations, confirmations fonctionnent
- `TransactionLine` créée dans Drift local — horodatée
- `SyncStatusBar` offline permanent — rappel discret de l'état
- Pas d'indication "en attente de sync" visible par l'utilisateur — l'action est considérée comme faite
