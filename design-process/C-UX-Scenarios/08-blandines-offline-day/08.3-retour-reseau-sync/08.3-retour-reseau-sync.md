# 08.3 — Retour Réseau — Sync Automatique

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 08: Blandine's Offline Day |
| **Step** | 08.3 |
| **Platform** | Mobile Android mid-range |

## Overview

**Page Purpose:** Le réseau revient — l'app détecte la reconnexion, sync silencieuse automatique depuis la queue Drift vers le backend — l'utilisateur ne fait rien, tout se règle en arrière-plan.

**Entry Context:** Vient de 08.2 — actions accumulées dans Drift local. Réseau revenu.

**Exit Action:** `SyncStatusBar` passe "Sync en cours" → "Synchronisé" — backend à jour, état nominal ✓

**On-Page Interactions:**
- `SyncStatusBar` passe offline → "Sync en cours" (spinner discret) → "Synchronisé" (icône check)
- `AlertBanner` info optionnel — "Synchronisation terminée" — 2 sec si actions importantes syncées
- L'utilisateur continue son travail sans interruption — la sync est totalement silencieuse
- Drift local et backend = état identique après sync
