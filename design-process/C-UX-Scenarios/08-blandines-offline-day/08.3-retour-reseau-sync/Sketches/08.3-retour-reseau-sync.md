# Sketch Hi-Fi — 08.3 Retour Réseau — Sync Automatique

> Réseau revenu — l'app détecte la reconnexion automatiquement.
> Sync silencieuse depuis la queue Drift vers le backend.
> L'utilisateur ne fait RIEN — tout se règle en arrière-plan.
> SyncStatusBar : offline → syncing → synced.
> Pushs FCM en queue envoyées automatiquement.

## Annotations — Retour Réseau Sync

### Timeline SyncStatusBar complète (scénario 08)

```
Contexte : 3 ventes créées offline, 2 heures hors ligne

T-120min : réseau coupe → SyncStatusBar ambre 🔌
T-0min   : réseau revient → SyncStatusBar spinner ↻ "Sync en cours"
T+2s     : vente 1 (Tomates) syncée → badge _local_ disparu
T+3s     : vente 2 (Poivrons) syncée → badge disparu
T+5s     : vente 3 (Bananes) syncée → badge disparu
T+5s     : Pushs FCM en queue envoyées (clôture, alertes, etc.)
T+5s     : SyncStatusBar vert ● "Synchronisé · à l'instant"
T+5s     : AlertBanner vert "Sync terminée · 3 ventes" (3s)
T+8s     : AlertBanner dismiss → état nominal complet
```

### Règle AlertBanner post-sync

```
AlertBanner "Sync terminée" affiché SI ET SEULEMENT SI :
  La queue contenait des actions (ventes, clôtures, livrisons)
  auto-dismiss 3s

AlertBanner ABSENT si :
  Queue vide (utilisateur n'a pas agi offline)
  Sync en arrière-plan silencieuse (update données uniquement)
```
