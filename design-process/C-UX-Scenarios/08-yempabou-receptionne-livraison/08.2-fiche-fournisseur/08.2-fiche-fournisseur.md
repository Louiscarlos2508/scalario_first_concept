## Overview

**Page Purpose:** Vue 360° d'un fournisseur — coordonnées, historique des commandes/réceptions, produits fournis, statistiques d'achats, action principale "Réceptionner livraison".

**Entry Context:** Depuis Liste fournisseurs (08.1) → tap fournisseur. OU depuis notification "Livraison attendue".

**Exit Action principale:** Tape **"Réceptionner livraison"** (si commande en attente) → Réception marchandise (08.3).
**Exit Action secondaire:** Tape "Nouvelle commande" → formulaire commande fournisseur.

**Navigation:**
- **Breadcrumb desktop:** `Boutique > Fournisseurs > [Nom]`
- Mobile : back + nom

## Sections / Layout

### 1. Header fournisseur
- Logo / initiales + nom
- Catégorie (badge)
- Téléphone (tap → appel)
- WhatsApp (tap → message)
- Adresse (optionnel)
- Date début relation

### 2. Action sticky / CTA principal
- Si commande en attente : **"Réceptionner livraison du JJ/MM"** (gros bouton primaire)
- Sinon : **"Nouvelle commande"** (secondaire)

### 3. Stats (cards)
- Total achats (mois / année / à vie)
- Nombre de commandes
- Délai moyen de livraison
- Dernière livraison

### 4. Commandes en cours
Liste compacte :
- Date commande
- Statut : `En attente` / `Partiellement reçue` / `À valider`
- Total commandé
- Tap → réception (08.3)

### 5. Historique commandes (collapsible)
Toutes les commandes passées :
- Date | Total | Statut | Tap → détail

### 6. Produits fournis (top 10)
- Liste des produits que ce fournisseur livre habituellement
- Tap → fiche produit

### 7. Notes
Champ texte libre (conditions paiement, contact privilégié, etc.)

## On-Page Interactions

- Tap téléphone/WhatsApp
- Édition fiche
- Archiver fournisseur
- Filtre historique commandes (période)

## Données affichées

- Supplier entity
- PurchaseOrders liés
- Produits fournis (relation)
- Calculs agrégés

## Pourquoi cette page est nécessaire

- Pas de vue dédiée fournisseur aujourd'hui
- Doit centraliser toutes les infos pour décider rapidement (passer commande, vérifier historique, gérer une dette)
- L'action "Réceptionner" doit être 1 tap depuis la fiche
