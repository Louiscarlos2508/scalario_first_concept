# Sketch Hi-Fi — 09.1 Catalogue Produits

> Blandine gère son catalogue depuis mobile ou web (Flutter Web PWA).
> Liste complète des produits : nom / catégorie / prix / input_type / statut.
> ActionButton "Ajouter un produit" above the fold — primaire.
> Tap produit existant → mode édition (même formulaire 09.2).
