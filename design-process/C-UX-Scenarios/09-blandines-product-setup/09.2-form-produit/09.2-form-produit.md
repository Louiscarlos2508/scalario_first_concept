# 09.2 — FormWidget Produit

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 09: Blandine's Product Setup |
| **Step** | 09.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine saisit tous les paramètres du produit — dont le `pos_type` qui détermine le rendu dans le POS du Commercial.

**Entry Context:** Vient de 09.1 via tap "Ajouter un produit" (ou édition produit existant).

**Exit Action:** Tap "Enregistrer" → step 09.3.

**On-Page Interactions:**
- `TextInput` nom produit
- `ChipSelector` catégorie (depuis JSON)
- `ChipSelector` `pos_type` : Vrac (poids) / Unité (pièce) / Service / Autre
- `TextInput` unité de vente (kg / pièce / botte / sac / caisse) — adapté selon `pos_type`
- `NumberInput` prix unitaire (Roboto Mono — FCFA)
- `NumberInput` durée fraîcheur en jours (0 = pas de limite)
- `NumberInput` taux de perte attendu en % (ex: 15% pour tomates)
- `NumberInput` seuil alerte stock minimum (déclenche `AlertBanner` Blandine)
