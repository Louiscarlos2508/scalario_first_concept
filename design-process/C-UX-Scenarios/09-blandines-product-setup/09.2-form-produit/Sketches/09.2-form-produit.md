# Sketch Hi-Fi — 09.2 FormWidget Produit

> Blandine saisit tous les paramètres d'un produit depuis mobile ou web.
> Le `input_type` est le champ central — il détermine le rendu dans le POS du Commercial.
> Formulaire adaptatif : l'unité de vente se pré-remplit selon le `input_type` choisi.
> CTA "Enregistrer" désactivé tant que nom + input_type + prix ne sont pas remplis.
