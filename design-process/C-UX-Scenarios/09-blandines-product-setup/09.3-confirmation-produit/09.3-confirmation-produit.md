## Overview

**Page Purpose:** Blandine voit le récap complet du produit configuré, confirme — le produit est disponible immédiatement dans le POS du Commercial avec le rendu adapté au `input_type`.

**Entry Context:** Vient de 09.2 via tap "Enregistrer".

**Exit Action:** Tap "Confirmer" → produit enregistré Drift + sync backend → retour Catalogue ✓

**On-Page Interactions:**
- `ConfirmationDialog` — récap : nom / catégorie / input_type / unité / prix / fraîcheur / taux perte / seuil alerte
- Aperçu rendu POS : "Dans le POS, ce produit apparaîtra comme : [Tomates — saisie poids kg]"
- `ActionButton` "Confirmer" — primaire
- Post-confirmation : produit dans Drift → sync backend → disponible dans `ProductSelector` du Commercial
