### Comportement DiffCard (édition)

```
Règle affichage DiffCard :
  Comparer valeurs formulaire vs Drift avant soumission
  Afficher seulement les champs modifiés
  Champ NON modifié → absent de la diff (pas de ligne)
  Si AUCUN champ modifié → RecapCard normale (pas de DiffCard)
  Mention "_X, Y : inchangés_" listant les champs non modifiés

Format diff :
  Avant : ~~valeur~~ (strikethrough color-neutral-400 italic)
  Après : valeur (Inter 14sp 600 color-neutral-900)
  Flèche → entre avant et après
```
