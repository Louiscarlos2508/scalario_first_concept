# 09.1 — Utilisateurs Liste + Rôles · Phase 4 UX Spec

## Identité de la page
- **Nom** : Équipe & Utilisateurs — Liste
- **Scénario** : 09 — Blandine Ajuste Sa Configuration
- **Persona** : Blandine Konaté, Propriétaire
- **Plateforme** : Desktop
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Blandine de voir d'un coup d'œil qui a accès à quoi dans sa boutique, avec une distinction visuelle claire des rôles, avant d'ajouter ou de modifier un membre d'équipe.

## Point d'entrée
Navigation depuis le menu principal → item "Équipe" dans la sidebar.

## Sections

### 1. En-tête de page
Titre "Équipe & Utilisateurs" avec bouton CTA "Nouvel utilisateur" en bleu (#1A73E8) à droite.

### 2. Cartes Résumé de Rôles
Trois cartes horizontales montrant les rôles disponibles avec leur nombre d'utilisateurs et leurs permissions résumées :
- **Vendeur** (3 utilisateurs) : POS uniquement
- **Responsable** (1 utilisateur) : POS + Stock + Rapports partiels
- **Propriétaire** (1 utilisateur) : Accès complet

Clé UX : ces cartes permettent à Blandine de comprendre les niveaux d'accès *avant* d'agir — supprime la crainte d'attribuer le mauvais rôle.

### 3. Barre de recherche + Filtres
Champ de recherche texte libre + chips de filtre : Tous / Actifs / Inactifs.

### 4. Tableau des utilisateurs
Colonnes : Employé (avatar + nom) / Rôle (badge coloré) / Statut (Actif/Inactif) / Dernière connexion / Actions (éditer, désactiver).
5 utilisateurs affichés avec données réalistes burkinabè.

### 5. Actions par ligne
Icône crayon (éditer) et icône pause/disable (désactiver) sur chaque ligne. Désactiver = rend le compte inactif sans suppression (traçabilité).

## Décision UX clé
Les cartes de rôles en haut de page constituent la différence principale par rapport à une liste classique : elles donnent une compréhension immédiate des niveaux d'accès avant toute action, réduisant l'anxiété de Blandine liée au risque de mal configurer les permissions.

## Navigation
- Clic "Nouvel utilisateur" → 09.2 Création/Édition
- Clic icône crayon → 09.2 Édition (utilisateur pré-rempli)
- Sidebar → autres sections de configuration
