# 09.2 — Utilisateurs Création / Édition Rôle · Phase 4 UX Spec

## Identité de la page
- **Nom** : Nouveau membre de l'équipe — Formulaire de création
- **Scénario** : 09 — Blandine Ajuste Sa Configuration
- **Persona** : Blandine Konaté, Propriétaire
- **Plateforme** : Desktop
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Blandine de créer un compte employé en choisissant son rôle et en visualisant immédiatement les permissions associées, sans avoir à naviguer vers une autre page pour comprendre ce que chaque rôle autorise.

## Point d'entrée
Clic sur "Nouvel utilisateur" depuis la liste 09.1, ou clic icône crayon pour édition d'un utilisateur existant.

## Sections

### 1. Formulaire de création (panneau gauche — 60%)
Carte blanche avec :
- Champs : Prénom*, Nom*, Téléphone* (format international), Email (optionnel), PIN 4 chiffres*
- Sélecteur de rôle : radio-cards pour Vendeur / Responsable / Propriétaire
- Le rôle sélectionné est mis en évidence (border bleue + fond légèrement coloré)
- Bouton primaire "Créer l'utilisateur" en bas

### 2. Panneau Permissions (panneau droit — 40%, sticky)
Se met à jour dynamiquement selon le rôle sélectionné. Affiche :
- Titre "Permissions — [Rôle sélectionné]"
- Liste des modules avec check (✅ accordé) ou croix (❌ refusé)
- Encadré info jaune pour les nuances importantes
- Lien "Comparer avec Propriétaire" en bas du panneau

### 3. État d'édition
Si édition d'un utilisateur existant, les champs sont pré-remplis. Bouton devient "Enregistrer les modifications". Ajout d'un bouton secondaire "Désactiver ce compte" en rouge ghost.

## Décision UX clé
Le panneau de permissions dynamique côté droit supprime complètement la friction cognitive : Blandine voit exactement ce que l'employé pourra ou ne pourra pas faire, en temps réel, pendant qu'elle choisit le rôle. Pas besoin de mémoriser les rôles, pas de risque d'erreur.

## Navigation
- Clic "Créer l'utilisateur" → retour liste 09.1 avec toast de confirmation + nouvel employé en haut de liste
- Clic "Annuler" → retour liste 09.1 sans modification
- Clic "Comparer avec Propriétaire" → modal de comparaison
