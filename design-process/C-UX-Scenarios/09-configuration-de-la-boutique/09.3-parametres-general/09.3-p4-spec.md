# 09.3 — Paramètres Général · Phase 4 UX Spec

## Identité de la page
- **Nom** : Paramètres — Général
- **Scénario** : 09 — Blandine Ajuste Sa Configuration
- **Persona** : Blandine Konaté, Propriétaire
- **Plateforme** : Desktop
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Blandine de configurer l'identité complète de sa boutique (nom, logo, secteur, contact) ainsi que les paramètres régionaux (devise, fuseau horaire, langue) qui affectent l'ensemble de l'expérience Scalario.

## Point d'entrée
Navigation sidebar → "Paramètres" → sous-onglet "Général" (ou page par défaut des Paramètres).

## Sections

### 1. Identité de la boutique
- Zone d'upload logo (cercle, border dashed, "Uploader le logo")
- Nom de la boutique (texte)
- Secteur d'activité (dropdown)
- Téléphone boutique
- Adresse

### 2. Localisation & Devise
Pays, Ville, Devise (XOF par défaut pour marché Burkina Faso), Fuseau horaire.

### 3. Langue & Format
Langue de l'application, format de date, format d'heure. Ces paramètres s'appliquent à l'affichage de toute l'interface.

### 4. Zone dangereuse
Bouton "Supprimer la boutique" rouge avec texte d'avertissement explicite. Action irréversible — nécessite confirmation double.

### 5. Barre de sauvegarde (sticky bas)
Bouton "Enregistrer les modifications" + bouton "Annuler" toujours visibles sans scroll.

## Décision UX clé
La devise XOF est pré-sélectionnée par défaut pour le marché cible Burkina Faso, réduisant la friction d'onboarding. La zone dangereuse est physiquement séparée des autres sections par un espace important et une couleur distincte, réduisant le risque d'action accidentelle.

## Navigation
- Clic "Enregistrer" → toast de confirmation "Paramètres enregistrés ✓", reste sur la page
- Clic "Annuler" → reset des champs non sauvegardés
- Navigation sidebar → autres sections (Utilisateurs, Intégrations, etc.)
