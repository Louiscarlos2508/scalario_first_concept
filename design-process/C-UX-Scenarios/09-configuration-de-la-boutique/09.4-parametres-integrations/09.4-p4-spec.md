# 09.4 — Paramètres Intégrations · Phase 4 UX Spec

## Identité de la page
- **Nom** : Paramètres — Intégrations
- **Scénario** : 09 — Blandine Ajuste Sa Configuration
- **Persona** : Blandine Konaté, Propriétaire
- **Plateforme** : Desktop
- **Style** : Modern SaaS + Professional/Corporate

## Objectif
Permettre à Blandine de connecter et tester ses services de paiement mobile money (Orange Money, Moov Money) et d'accéder aux informations d'API Scalario pour d'éventuelles intégrations tierces.

## Point d'entrée
Navigation sidebar → "Paramètres" → onglet ou lien "Intégrations".

## Sections

### 1. Orange Money (connecté)
Carte avec badge "Connecté" vert. Affiche les champs configurés (numéro marchand, clé API masquée, webhook). Bouton "Tester la connexion" + indicateur du dernier test réussi. Lien "Déconnecter" en rouge discret.

### 2. Moov Money (non configuré)
Carte avec badge "Non configuré" gris. Champs vides. Bouton "Configurer" en bleu comme CTA principal.

### 3. API Scalario (informationnel)
Carte collapsible avec clé API publique masquée + bouton copie, lien documentation, avertissement sécurité pour la clé secrète.

## Décision UX clé
Le badge de statut coloré (vert/gris) sur chaque carte permet à Blandine d'identifier l'état de ses intégrations en un coup d'œil sans avoir à ouvrir chaque carte. Le résultat du dernier test avec timestamp rassure sur la fiabilité de la connexion active (critique pour la confiance dans les paiements).

## Navigation
- Clic "Tester la connexion" → indicateur de chargement puis résultat inline
- Clic "Configurer" (Moov Money) → expansion de la carte avec champs à remplir
- Clic "Déconnecter" → confirmation modal avant déconnexion
- Navigation sidebar → autres sections Paramètres
