# 10.2 — FormWidget Employé

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 10: Blandine's Team Management |
| **Step** | 10.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine saisit les informations du nouvel employé — identité, rôle, département — et un mot de passe temporaire est auto-généré.

**Entry Context:** Vient de 10.1 via tap "Ajouter un employé" (ou édition employé existant).

**Exit Action:** Tap "Créer le compte" → step 10.3.

**On-Page Interactions:**
- `TextInput` prénom + nom
- `TextInput` numéro téléphone (= username unique)
- `ChipSelector` rôle : COMMERCIAL / MANAGER (OWNER réservé — 1 seul par tenant)
- `TextInput` département (optionnel — si configuré dans le tenant JSON)
- Mot de passe temporaire : auto-généré, affiché masqué, copiable
- `Toggle` activation biométrie (fingerprint / Face ID) — configurable

## Composants BDUI

| Composant | État | Notes |
|-----------|------|-------|
| `TextInput` | prénom + nom | Obligatoires |
| `TextInput` | téléphone | Unique par tenant — vérifié à la création |
| `ChipSelector` | rôle | COMMERCIAL / MANAGER — OWNER non sélectionnable |
| `TextInput` | département | Optionnel — depuis JSON tenant |
| `PasswordField` | mot de passe temp | Auto-généré — affiché masqué — bouton copier |
| `Toggle` | biométrie | Activer fingerprint/Face ID pour cet employé |
