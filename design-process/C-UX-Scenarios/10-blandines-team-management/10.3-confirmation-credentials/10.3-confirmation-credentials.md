# 10.3 — Confirmation + Credentials

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 10: Blandine's Team Management |
| **Step** | 10.3 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Le compte est créé — Blandine voit le récap et les credentials (username + mot de passe temporaire) à communiquer à l'employé. L'employé peut se connecter immédiatement.

**Entry Context:** Vient de 10.2 via tap "Créer le compte".

**Exit Action:** Blandine copie / note les credentials → retour Vue Équipe ✓

**On-Page Interactions:**
- `ConfirmationDialog` récap : nom, rôle, département, téléphone
- Credentials affichés : username (= téléphone) + mot de passe temporaire (visible + bouton copier)
- Bouton "Partager via WhatsApp" — deeplink WhatsApp avec credentials pré-remplis
- `AlertBanner` vert "Compte créé — [Prénom] peut se connecter maintenant"
- Note : l'employé devra changer son mot de passe au premier login (configurable JSON)
