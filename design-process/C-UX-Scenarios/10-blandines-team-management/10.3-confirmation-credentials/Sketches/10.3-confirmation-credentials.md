### Sécurité — règles credentials

```
Mot de passe visible sur cet écran (contrairement au formulaire) :
  Justification : Blandine DOIT communiquer le mdp à l'employé
  Le masquer ici créerait une friction inutile (elle doit le copier/dicter)

Le mdp n'est jamais envoyé en clair côté backend :
  Stocké hashé (bcrypt) dans Supabase Auth
  Seul le mdp en clair est visible dans l'UI au moment de la création
  Après fermeture de cet écran, le mdp n'est plus accessible nulle part

Change password au 1er login :
  configurable JSON : change_password_on_first_login: true
  S23 : scénario dédié au changement mdp 1er login

Session invalidation post-reset :
  Ancien token JWT invalidé immédiatement via Supabase Auth signOut
  L'employé est déconnecté et doit se reconnecter avec le nouveau mdp
```
