# 10.1 — Stock Réception Marchandise · Phase 4 UX Spec

## Identité de la page
- **Nom** : Réception Livraison — Saisie
- **Scénario** : 10 — Le Gestionnaire Réceptionne une Livraison
- **Persona** : Cheick Ouédraogo, Responsable
- **Plateforme** : Mobile
- **Style** : Mobile-first, fonctionnel, rapide

## Objectif
Permettre au gestionnaire d'enregistrer rapidement une livraison fournisseur en saisissant les quantités reçues par produit, avec application automatique du Taux de Frotte sur les produits frais — le tout debout devant le fournisseur.

## Point d'entrée
Navigation depuis le dashboard gestionnaire → module "Réceptions" → bouton "Nouvelle réception".

## Sections

### 1. En-tête sticky (dark bar)
Back arrow ← | Titre "Réception livraison" | Bouton "Confirmer" vert (accès rapide haut d'écran).

### 2. Fournisseur (carte)
Sélecteur fournisseur + référence bon de commande avec lien "Voir →" + date/heure automatique de réception.

### 3. Articles reçus (carte)
Liste des produits attendus du bon de commande. Chaque ligne affiche :
- Nom + catégorie
- Quantité commandée (référence) vs champ de saisie quantité reçue (pre-rempli avec quantité commandée)
- Badge Taux de Frotte automatique sur les produits frais (pill verte)
- Badge "X manquants" en jaune si quantité reçue < commandée

### 4. Pertes & Dégâts (carte collapsible)
Section optionnelle pour noter les produits endommagés à la réception. Collapsed par défaut pour ne pas surcharger l'interface.

### 5. Récapitulatif Frotte (carte fond jaune pâle)
Synthèse du Taux de Frotte appliqué automatiquement : stock entrant → stock effectif après déduction. Information transparente pour la traçabilité.

### 6. Barre de confirmation (sticky bas)
Bouton "Confirmer la réception" pleine largeur, bleu, toujours visible.

## Décision UX clé
Le Taux de Frotte s'applique automatiquement sur les produits frais configurés et est affiché de façon transparente — le gestionnaire n'a pas à le calculer manuellement, éliminant une source d'erreur majeure. Le récapitulatif en bas permet une vérification finale avant confirmation.

## Navigation
- Clic "Confirmer la réception" → 10.2 Stock Inventaire/Ajustement + toast de confirmation
- Back arrow ← → annulation (avec confirmation si données saisies)
