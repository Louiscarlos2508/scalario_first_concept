# 10.2 — Sélection profil utilisateur

**Statut écran existant :** ❌ **CRÉER** — page absente. EmployeePinScreen + TeamPinScreen existent comme briques mais l'écran de sélection multi-profils est manquant.

## Page Metadata

| Property | Value |
|----------|-------|
| Scenario | 10: Yempabou met sa boutique en route (et tous les démarrages quotidiens) |
| Page Number | 10.2 |
| Platform | Mobile + Tablette + Desktop |

## Overview

**Page Purpose:** Permettre à plusieurs utilisateurs de partager le même device (cas paliers Solo et Boutique) en sélectionnant leur profil avec PIN. Switch rapide entre patron, gérante, vendeurs.

**Entry Context:**
- Première installation après onboarding (10.1)
- Chaque démarrage de l'app (si plusieurs profils créés)
- Switch profil depuis le menu utilisateur (logout)
- Reprise après session lock par inactivité

**Exit Action:** Sélection d'un profil → saisie PIN (4 chiffres) → succès → redirige vers le dashboard correspondant au rôle (Patron/Gérant/Vendeur).

**Navigation:**
- Pas de breadcrumb (écran de connexion racine)
- Pas de back (sauf si vient d'un switch utilisateur, alors back annule le switch)

## Sections / Layout

### 1. Header
- Logo Scalario + nom boutique (tenant actif)
- Date + heure (rassurant)

### 2. Grille des profils
Chaque profil sous forme de tile :
- Avatar/initiales en grand
- Nom complet
- Rôle (badge couleur : Patron / Gérant / Vendeur / Commercial)
- Indicateur "actif récemment" (last login)

Layout responsive :
- Mobile : 2 colonnes, scroll vertical
- Tablette : 3-4 colonnes
- Desktop : 4-6 colonnes centrées

### 3. Action secondaire
- "Connexion patron par email/mot de passe" (lien discret) — pour récupération si PIN oublié
- "Aucun profil ? Créer le premier compte" (si liste vide)

### 4. Pied de page
- Version app + statut sync (point vert/orange/rouge)
- "Mode hors ligne" si pas de connexion

## Step 2 — Saisie PIN

Après tap sur un profil :
- Modal/sheet centré
- Avatar + nom du profil sélectionné
- Pavé numérique (4 chiffres)
- Indicateur visuel des chiffres saisis (4 dots)
- Bouton "Annuler" (revient à la grille)
- Validation auto au 4ème chiffre
- Erreur : shake + message "PIN incorrect" + reset
- Après 3 erreurs : verrouillage 30s

## On-Page Interactions

- Tap profil → ouvre PIN
- Long press profil → menu contextuel (voir profil, modifier — si user actuel = patron)
- Recherche profil (si > 8 profils)
- Switch tenant (si l'utilisateur a accès à plusieurs boutiques — palier Pro)

## Données affichées

- Liste des `LocalProfile` du device (distincts des Supabase users)
- Pour chaque : id, name, role, avatar, lastLogin, pinHash

## États

- **Aucun profil** → message + bouton "Créer le premier compte"
- **1 seul profil** → bypass automatique vers PIN direct
- **Plusieurs profils** → grille
- **Mode offline** → indicateur visible, fonctionne quand même
- **Tenant suspendu** → écran billing à la place

## Lien avec EmployeePinScreen / TeamPinScreen existants

- **EmployeePinScreen** = saisie PIN d'un seul user (réutilisable comme step 2)
- **TeamPinScreen** = CRUD des profils PIN locaux (paramétrage, pas auth)
- **Cette page (10.2)** = écran d'orchestration manquant qui présente la grille et déclenche EmployeePinScreen

## Pourquoi cette page est nécessaire

- Phase 1 supporte les paliers Solo (5K) et Boutique (7.5K) avec **multi-comptes sur le même appareil**
- Différenciation clé : prix bas du local + permissions par rôle
- Le PIN local est rapide (vs login email/mot de passe Supabase utilisé en cloud uniquement)
- Permet au patron + vendeurs de partager une tablette comptoir sans confusion

## Sécurité

- PIN hashé localement (pas en clair)
- Verrouillage temporaire après 3 erreurs
- Récupération via login Supabase patron uniquement
- Le patron peut reset le PIN d'un employé depuis Gestion équipe (10.4)
