# 11.2 — Rapports Stock · Phase 4 UX Spec

## Identité de la page
- **Nom** : Rapports — Stock
- **Scénario** : 11 — Blandine Lit Ses Rapports
- **Persona** : Blandine Konaté, Propriétaire
- **Plateforme** : Desktop
- **Style** : Modern SaaS + Analytics + AI-Enhanced

## Objectif
Permettre à Blandine de consulter les mouvements de stock de la semaine (réceptions, ventes, ajustements, pertes Frotte) et d'obtenir via GenUI une liste priorisée des produits à réapprovisionner — pour prendre une décision concrète en quelques minutes.

## Point d'entrée
Navigation depuis la sidebar → "Rapports" → sous-section "Stock", ou depuis Rapports Ventes 11.1.

## Sections

### 1. En-tête + Sélecteur de période
Titre "Rapports — Stock" avec sélecteur de période (Cette semaine actif par défaut).

### 2. Rangée KPI (4 cartes)
- Réceptions : 3 livraisons, 18 produits
- Pertes Frotte : −12.4 kg produits frais
- Produits critiques : 4 (badge rouge)
- Valeur stock total : 1 240 000 XOF

### 3. Mouvements de la semaine (tableau avec tabs)
Table complète avec filtres : Tous / Réceptions / Ventes / Ajustements. Chaque ligne colorée selon le type de mouvement : vert (réception ↑), bleu (vente ↓), gris (ajustement ↔). Colonnes : Produit / Mouvement / Quantité / Date / Responsable.

### 4. Niveaux actuels (grille compacte)
Vue d'ensemble visuelle de tous les produits avec barres de stock colorées selon le niveau : rouge (critique), orange (bas), vert (OK). Blandine voit immédiatement quels produits sont en danger.

### 5. GenUI — Analyse IA (carte premium)
Question affichée : "Qu'est-ce que je dois réapprovisionner en priorité ?"
Réponse générée : liste priorisée avec urgence colorée (rouge/orange/jaune), stock restant, prévision de rupture basée sur les ventes moyennes journalières.
Bouton d'action : "Générer bon de commande →" transformant l'analyse en action directe.

## Décision UX clé
La combinaison du tableau de mouvements (traçabilité) + grille niveaux actuels (visibilité instantanée) + GenUI (recommandation actionnable) couvre les trois besoins analytiques de Blandine : comprendre ce qui s'est passé, voir l'état actuel, et décider quoi faire ensuite — sans jamais quitter la page.

## Navigation
- Clic "Générer bon de commande →" → création de bon de commande pré-rempli (fonctionnalité future)
- Chips filtres tableau → filtrage inline
- Navigation sidebar → autres rapports ou retour dashboard
