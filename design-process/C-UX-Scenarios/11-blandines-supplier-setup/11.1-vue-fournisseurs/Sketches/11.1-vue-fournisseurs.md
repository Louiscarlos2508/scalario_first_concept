# Sketch Hi-Fi — 11.1 Vue Fournisseurs

> Blandine liste ses fournisseurs — nom, produits associés, dernière livraison.
> ActionButton "Ajouter un fournisseur" above the fold — primaire.
> Tap fournisseur → mode édition (prix d'achat à jour après négociation).
> Dernière livraison : date + montant total — indicateur d'activité.
