# 11.2 — FormWidget Fournisseur

## Page Metadata

| Property | Value |
|----------|-------|

| **Step** | 11.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine saisit les informations du fournisseur et associe les produits qu'il livre avec leur prix d'achat.

**Entry Context:** Vient de 11.1 via tap "Ajouter un fournisseur".

**Exit Action:** Tap "Enregistrer" → step 11.3.

**On-Page Interactions:**
- `TextInput` nom fournisseur
- `TextInput` téléphone contact
- `ProductPriceList` — sélection produits depuis catalogue + prix d'achat par produit (Roboto Mono)
- Marge calculée en temps réel par produit (prix vente - prix achat) — Inter secondaire
- `ActionButton` "Enregistrer" — actif dès nom + 1 produit saisis
