# Sketch Hi-Fi — 11.2 FormWidget Fournisseur

> Blandine saisit infos fournisseur + associe les produits livrés avec leurs prix d'achat.
> Marge calculée en temps réel par produit : (Prix vente - Prix achat) / Prix vente.
> Prix achat > Prix vente → marge rouge → warning inline — erreur critique détectable.
> CTA "Enregistrer" actif dès nom + 1 produit avec prix saisis.

Règle marge négative — non bloquante :
  La marge négative est un WARNING (pas une erreur bloquante)
  Blandine peut avoir un prix promo, un produit d'appel, ou une saisie erronée
  Elle peut enregistrer et corriger plus tard
  AlertBanner warning + KPICard rouge = signal clair sans bloquer
  CTA reste actif — responsabilité de Blandine

Marge seuils :
  > 30 %  : color-success (vert) ●
  10-30 % : color-neutral-900 (neutre) ●
  < 10 %  : color-warning (orange) ●
  < 0 %   : color-danger (rouge) ⚠ + AlertBanner warning
