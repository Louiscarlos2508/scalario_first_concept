| Property | Value |

## Overview

**Page Purpose:** Blandine voit le récap du fournisseur configuré — produits associés, marges calculées — et confirme. Le fournisseur est disponible dans le flow de réception livraison Ibrahim.

**Entry Context:** Vient de 11.2 via tap "Enregistrer".

**Exit Action:** Tap "Confirmer" → fournisseur actif → retour Vue Fournisseurs ✓

**On-Page Interactions:**
- `ConfirmationDialog` — nom, téléphone, produits + prix achat + marge par produit
- `ActionButton` "Confirmer" — primaire
- Post-confirmation : fournisseur disponible dans `DeliveryCard` Ibrahim (S05)
