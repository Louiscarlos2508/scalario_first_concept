# 12.1 — Vue Rapports

## Page Metadata

| Property | Value |
|----------|-------|

## Overview

**Page Purpose:** Blandine sélectionne la période d'analyse — les métriques clés se chargent immédiatement depuis Drift local.

**Entry Context:** Premier step — Blandine navigue vers "Rapports" depuis son dashboard OWNER.

**Exit Action:** Période sélectionnée → métriques chargées → step 12.2.

**On-Page Interactions:**
- `PeriodSelector` — Aujourd'hui / Cette semaine / Ce mois / Personnalisé
- Métriques résumées chargées immédiatement depuis Drift (pas d'attente réseau)
- `KPICard` CA période, marge brute, pertes totales — aperçu avant rapport complet

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Blandine, fin de journée ou matin. Veut comprendre la performance sur une période.

**Mental State (Q4):**
- Hope: Voir les chiffres réels, comprendre la tendance
- Worry: Découvrir une tendance négative qu'elle n'avait pas vue

**Discovery Method (Q6):** Dashboard OWNER → tab "Rapports" dans navigation OWNER JSON.
