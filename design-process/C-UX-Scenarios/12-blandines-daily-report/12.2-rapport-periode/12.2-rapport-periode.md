# 12.2 — Rapport Période

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 12: Blandine's Daily Report |
| **Step** | 12.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Vue complète du rapport pour la période sélectionnée — CA avec courbe, marge, top produits, pertes, mouvements stock. Chaque métrique est tappable pour drill-down.

**Entry Context:** Vient de 12.1 via sélection période.

**Exit Action:** Tap sur une métrique → step 12.3 (drill-down). Ou lecture seule → retour dashboard ✓

**On-Page Interactions:**
- `ChartWidget` CA — courbe ligne sur la période (jour par jour) — vert si tendance positive
- `KPICard` CA total période (Roboto Mono grand)
- `KPICard` marge brute % + montant
- `RankingList` top 5 produits vendus (quantité + CA)
- `KPICard` pertes totales période (montant + taux vs taux_perte_pct attendu)
- `KPICard` nombre de transactions
- Chaque card = tappable → drill-down
