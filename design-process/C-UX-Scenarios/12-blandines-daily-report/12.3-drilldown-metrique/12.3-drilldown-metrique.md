# 12.3 — Drill-down Métrique

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 12: Blandine's Daily Report |
| **Step** | 12.3 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine tape sur une métrique du rapport et voit le détail — liste des transactions, déclarations de pertes, mouvements par produit — pour comprendre ce qui compose le chiffre.

**Entry Context:** Vient de 12.2 via tap sur une `KPICard` ou `ChartWidget`.

**Exit Action:** Compréhension atteinte → retour rapport période ✓

**On-Page Interactions:**
- Titre contextuel : "Pertes — Cette semaine" ou "Ventes — Aujourd'hui"
- `TransactionList` — liste lignes détaillées (date, montant, produit, responsable)
- `FilterChips` — filtrer par produit, par employé, par type
- Export optionnel (Phase 2) — PDF ou partage WhatsApp
