# Sketch Hi-Fi — 12.3 Drill-down Métrique

> Blandine tape sur une KPICard du rapport → liste détaillée de ce qui compose le chiffre.
> Titre contextuel : "Ventes — Cette semaine" ou "Pertes — Cette semaine".
> FilterChips : filtrer par commercial, par produit, par motif de perte.
> KPICard total filtré — mis à jour en temps réel selon les filtres actifs.

## Annotations — Drill-down Métrique

### Typographie

| Élément | Token DS | Font | Size |
|---------|----------|------|------|
| AppBar titre | `font-page-title` | Inter | 16sp 600 |
| AppBar subtitle | `text-caption` | Inter | 12sp 400 |
| KPI total filtré | `font-kpi-value` | Roboto Mono | 14sp 600 |
| Employé / Manager | `font-list-primary` | Inter | 13sp 500 |
| Timestamp | `text-caption` | Inter | 11sp 400 |
| Produits | — | Inter | 12sp 400 |
| Montant vente | `font-kpi-value` | Roboto Mono | 13sp 700 neutral-900 |
| Montant perte | `font-kpi-value` | Roboto Mono | 13sp 700 danger-600 |
| Motif chip | `text-overline` | Inter | 11sp 400 |

### Logique filtres temps réel

```
FilterChips → filtre la liste TransactionList localement (Drift)
Pas d'appel réseau — filtrage instantané en mémoire
KPICard total filtré = SUM des montants de la liste filtrée
Recalculé à chaque changement de filtre (< 50ms Drift SQLite)
```

### Composants DS référencés

| Composant | Fichier DS | Usage |
|-----------|------------|-------|
| `AppBar` | 08-navigation-layout.md | navigation contextuelle (← retour) |
| `KPICard` | 02-data-display.md | total filtré — mis à jour temps réel |
| `FilterChips` | 04-selection.md | filtres par commercial / motif / type |
| `TransactionList` | 02-data-display.md | liste ventes / pertes / mouvements |
| `BottomNav` | 08-navigation-layout.md | 5 tabs OWNER |
