## Overview

**Page Purpose:** Blandine voit toutes les alertes disponibles avec leur statut actif/inactif — peut en activer/désactiver en un tap ou en configurer une en détail.

**Entry Context:** Premier step — Blandine navigue vers Settings → "Mes alertes".

**Exit Action:** Tap sur une alerte → step 13.2 pour configuration détaillée.

**On-Page Interactions:**
- `AlertConfigList` — liste alertes disponibles dans le template JSON
- `Toggle` par alerte — activer/désactiver en 1 tap
- Résumé config actuelle (seuil, heure) visible sous chaque alerte
- Tap alerte → config détaillée (13.2)

---

## Entry Context (Step 1 only)

**User Situation (Q3):** Blandine, OWNER. Première configuration ou ajustement après notifications non pertinentes.

**Mental State (Q4):**
- Hope: Configurer rapidement les alertes importantes, ignorer les autres
- Worry: Rater une vraie alerte parce qu'elle a tout désactivé

**Discovery Method (Q6):** Dashboard OWNER → icône Settings ou tab Paramètres → section "Mes alertes".

## Types d'alertes (retail_fresh_produce.json)

| Alerte | Déclencheur | Défaut |
|--------|-------------|--------|
| Stock critique | Article < seuil_alerte_stock | Actif |
| Clôture non faite | Heure configurable sans clôture | Actif |
| Livraison avec écarts | Écart > seuil JSON | Actif |
| Résumé soir | Heure fixe (défaut 19h) | Actif |
| Perte déclarée | Chaque déclaration Ibrahim | Optionnel |
