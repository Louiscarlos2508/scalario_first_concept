Comportement Toggle rapide :
  T+0ms    : tap Toggle
  T+0ms    : Drift write local — alerte désactivée immédiatement
  T+0ms    : Toggle animation OFF (200ms)
  T+200ms  : opacity item 1.0 → 0.6 (fade sur 300ms)
  T+200ms  : Snackbar "X désactivée" + [Annuler]
  T+500ms  : sync queue backend (background)
  T+4000ms : Snackbar auto-dismiss
  Annuler  : Toggle ON · Drift rewrite · Snackbar dismiss

Règle Snackbar "Annuler" :
  → Disponible pendant 4s seulement
  → Si Blandine navigue ailleurs avant 4s : annulation impossible
  → Pas de dialog de confirmation pour toggle (action légère, réversible)

### Logique compteur sous-titre

```

  → "5 alertes — 0 actives" si toutes OFF (état edge case)
```
