# 13.2 — Config Alerte

## Overview

**Page Purpose:** Blandine configure en détail une alerte spécifique — seuil déclencheur, heure d'envoi, canal (push immédiate / résumé / les deux).

**Entry Context:** Vient de 13.1 via tap sur une alerte pour configuration détaillée.

**Exit Action:** Tap "Sauvegarder" → step 13.3.

**On-Page Interactions:**
- Titre alerte configurée
- `NumberInput` seuil déclencheur (ex: stock critique = 5 kg)
- `TimePicker` heure d'envoi (pour alertes programmées — résumé soir)
- `ChipSelector` canal : Push immédiate / Résumé uniquement / Les deux
- `Toggle` silence nocturne (ex: pas d'alertes entre 22h et 7h)
- Prévisualisation : "Tu recevras cette alerte quand le stock de Tomates descend sous 5 kg"
