# Sketch Hi-Fi — 13.2 Config Alerte

> Config détaillée d'une alerte spécifique — seuil, heure, canal, silence nocturne.
> Chaque type d'alerte a ses propres champs selon sa logique métier.
> AlertPreview = texte humanisé dynamique mis à jour à chaque changement.
> StickyFooter : [← Annuler] [Sauvegarder] — Sauvegarder actif dès qu'un champ est valide.
