### Impact Post-Configuration

```
Immédiat (Drift) :
  → FCM tokens mis à jour localement
  → Nouvelles règles alertes actives dès le prochain événement métier

Background sync (T+500ms) :
  → Config envoyée au backend
  → Backend met à jour les règles FCM côté serveur
  → Push suivantes respectent les nouveaux seuils/heures

Exemple flux post-config stock_critique à 3 kg :
  → Ibrahim vend 3 kg de tomates → stock Tomates = 2.5 kg
  → Drift détecte stock < seuil_alerte = 3 kg
  → Push FCM envoyée à Blandine : "Stock Tomates : 2.5 kg (seuil 3 kg)"
  → Si heure dans plage silence nocturne → push différée à la fin du silence
```
