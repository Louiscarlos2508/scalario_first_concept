# 14.1 — Historique Ventes

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 14: Commercial's Sale Return |
| **Step** | 14.1 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Commercial accède à la liste des ventes du jour pour retrouver la vente à annuler ou corriger.

**Entry Context:** Dashboard COMMERCIAL → section historique ou ActionButton "Historique ventes".

**Exit Action:** Tap sur une vente → 14.2 pour récap détaillé + annulation.

**On-Page Interactions:**
- `TransactionList` — ventes du jour (heure, montant, articles, statut)
- `FilterChips` — filtrer par heure, montant, statut (active / annulée)
- Tap vente → détail + option annulation
- Statut visuel : ventes annulées apparaissent barrées / grisées
