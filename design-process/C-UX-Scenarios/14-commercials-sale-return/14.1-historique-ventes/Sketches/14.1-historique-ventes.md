# Sketch Hi-Fi — 14.1 Historique Ventes (Commercial)

> Commercial consulte ses ventes du jour pour trouver celle à annuler.
> Entry : Dashboard COMMERCIAL → onglet Historique ou ActionButton "Mes ventes".
> Platform : Mobile Android uniquement — pas de web layout pour le COMMERCIAL.
> FilterChips : Tout / Actives / Annulées — filtre en temps réel.
> Tap vente → 14.2 détail + option annulation.

### Règle Total Sous-Titre

```
total_sous_titre = somme des ventes ACTIVES uniquement
  → ventes annulées exclues du total (montants déduits)
  → format : "{N} ventes · {total} FCFA" (Roboto Mono dans sous-titre)
  → 0 vente : "{N} ventes" uniquement (pas de montant FCFA)

TotalRow bottom :
  → filtre "Tout" : "{N} actives · {M} annulée(s) · {total} FCFA"
  → filtre "Actives" : "{N} ventes actives · {total} FCFA"
  → filtre "Annulées" : "{M} annulée(s) · {total_annulé} FCFA annulés"
```

### Restriction d'annulation

```
Ventes annulables :
  → status = "active" uniquement
  → créées aujourd'hui par ce commercial
  → pas de restriction horaire (peut corriger toute la journée)

Ventes NON annulables (tap → InfoCard en haut de 14.2) :
  → status = "annulée" (déjà annulée)
  → ventes d'un autre jour (historique passé — Blandine seule peut annuler)
```
