# 14.2 — Détail Vente + Annulation

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 14: Commercial's Sale Return |
| **Step** | 14.2 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Commercial voit le récapitulatif complet de la vente, saisit un motif obligatoire, puis confirme l'annulation.

**Entry Context:** Vient de 14.1 via tap sur une vente de la liste.

**Exit Action:** Tap "Confirmer annulation" → 14.3.

**On-Page Interactions:**
- Récap vente : heure, articles, quantités, montant total, mode paiement
- `ChipSelector` motif : Erreur saisie / Demande client / Article indisponible / Autre
- `TextInput` note optionnelle (obligatoire si motif = "Autre")
- `ActionButton` "Confirmer annulation" — destructif, couleur rouge/ambre
- `ConfirmationDialog` avant exécution : "Cette action est irréversible — le stock sera remis à jour"
