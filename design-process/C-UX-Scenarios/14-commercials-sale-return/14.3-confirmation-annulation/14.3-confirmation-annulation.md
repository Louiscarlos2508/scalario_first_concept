# 14.3 — Confirmation Annulation

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 14: Commercial's Sale Return |
| **Step** | 14.3 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** L'annulation est enregistrée — stock remis à jour, Blandine notifiée, Commercial protégé par la traçabilité.

**Entry Context:** Vient de 14.2 via tap "Confirmer annulation" + validation ConfirmationDialog.

**Exit Action:** `AlertBanner` vert "Vente annulée" → retour Dashboard COMMERCIAL ✓

**On-Page Interactions:**
- `AlertBanner` vert "Vente annulée — motif enregistré" — 2 sec
- Récap annulation : heure, montant annulé, motif, stock remis
- Blandine reçoit push FCM : "Vente annulée par [Commercial] — [motif]"
- Vente apparaît dans historique avec statut "Annulée" barré/grisé
