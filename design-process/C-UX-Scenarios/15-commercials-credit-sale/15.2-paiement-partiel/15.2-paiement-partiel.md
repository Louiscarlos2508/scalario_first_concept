# 15.2 — Paiement Partiel

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 15: Commercial's Credit Sale |
| **Step** | 15.2 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Commercial choisit le mode "Crédit" ou "Partiel", saisit le montant versé, le solde dû, l'échéance, et identifie le client.

**Entry Context:** Vient de 15.1 via tap "Procéder au paiement".

**Exit Action:** Tap "Confirmer vente crédit" → 15.3.

**On-Page Interactions:**
- `ChipSelector` mode paiement : Espèces / Mobile Money / Crédit total / Partiel (espèces + reste dû)
- Sélection "Crédit" ou "Partiel" révèle les champs additionnels
- `NumberInput` montant versé (0 si crédit total)
- `KPICard` solde dû calculé automatiquement (total − versé)
- `DatePicker` échéance remboursement
- `TextInput` nom client (obligatoire pour crédit/partiel)
- `TextInput` téléphone client (optionnel — pour rappel)
- Prévisualisation : "Solde dû : 4 500 FCFA — échéance 15 mai"
