# Sketch Hi-Fi — 15.2 Paiement Partiel / Crédit

> Écran paiement avec ChipSelector 4 modes — Espèces / Mobile Money / Crédit total / Partiel.
> Mode Crédit ou Partiel → champs conditionnels visibles : versé, solde dû, client, échéance.
> Solde dû = calculé en temps réel (total − versé) — Roboto Mono prominent.
> Nom client obligatoire pour tout crédit/partiel — protège Kofi si Blandine interroge.

### Logique Champs Conditionnels

```
Mode Espèces ou Mobile Money :
  → Pas de champs additionnels
  → CTA : "Confirmer paiement" (bg #FFCC00)

Mode Crédit total :
  → Affiche : KPICard Solde dû (= montant total) + FormCard client + DatePicker
  → Versé implicite = 0 FCFA
  → CTA : "Confirmer vente crédit" (bg color-warning-400)

Mode Partiel :
  → Affiche : NumberInput versé + KPICard Solde dû calculé + FormCard client + DatePicker
  → CTA : "Confirmer vente crédit" (bg color-warning-400) si champs complets

Transition Crédit → Partiel :
  → FormCard client et DatePicker déjà remplis → conservés
  → NumberInput versé : 0 → à saisir
```

### KPICard Solde Dû — Couleurs Réactives

```
solde_du > 0          → bg color-warning-50  · color-warning-700 (normal)
solde_du = 0          → bg color-success-50  · color-success-700 (paiement complet → suggestion basculer)
solde_du < 0          → bg color-danger-50   · color-danger-700  (erreur saisie → CTA disabled)
mode = Crédit total   → bg color-warning-50  · color-warning-700 (solde = total)
```
