# 15.3 — Confirmation Crédit

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 15: Commercial's Credit Sale |
| **Step** | 15.3 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** La vente crédit est enregistrée — créance tracée dans le système, Blandine notifiée, solde dû visible dans les rapports.

**Entry Context:** Vient de 15.2 via tap "Confirmer vente crédit".

**Exit Action:** `AlertBanner` vert "Vente crédit enregistrée" → retour Dashboard COMMERCIAL ✓

**On-Page Interactions:**
- `AlertBanner` vert "Vente crédit enregistrée — solde dû tracé" — 2 sec
- Récap : articles, montant total, montant versé, solde dû, client, échéance
- Blandine reçoit push FCM : "Vente crédit [Commercial] — [client] — solde : X FCFA — éch. JJ/MM"
- Stock mis à jour (articles sortis du stock même si non entièrement payés)

| Action | Effet | Destinataire |
|--------|-------|--------------|
| Vente crédit confirmée | Stock Drift mis à jour (articles sortis) | Système |
| Vente crédit confirmée | Créance créée dans rapport Blandine | Rapports OWNER |
| Vente crédit confirmée | Push FCM avec solde + échéance + client | Blandine (OWNER) |
| Vente crédit confirmée | TransactionLog avec mode "crédit/partiel" | Audit trail |
