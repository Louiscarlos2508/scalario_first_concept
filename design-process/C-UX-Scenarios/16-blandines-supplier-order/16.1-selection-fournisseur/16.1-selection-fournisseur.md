# 16.1 — Sélection Fournisseur

## Page Metadata

| Property | Value |

## Overview

**Page Purpose:** Blandine sélectionne le fournisseur à qui elle veut passer commande — liste depuis le catalogue fournisseurs (S11).

**Entry Context:** Dashboard OWNER → ActionButton "Nouvelle commande" ou depuis `AlertBanner` stock critique → "Commander".

**Exit Action:** Tap sur un fournisseur → 16.2 pour saisie des articles.

**On-Page Interactions:**
- `SupplierList` — fournisseurs actifs depuis catalogue S11 (nom, produits associés, dernier prix)
- `SearchBar` — recherche par nom fournisseur ou article
- Tap fournisseur → affiche aperçu articles associés + prix d'achat configurés
- Accès rapide si entrée depuis alerte stock : fournisseur suggéré pré-sélectionné
