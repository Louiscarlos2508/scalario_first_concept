# 16.2 — Saisie Commande

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 16: Blandine's Supplier Order |
| **Step** | 16.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine saisit les articles à commander et les quantités souhaitées — catalogue du fournisseur pré-chargé avec prix d'achat.

**Entry Context:** Vient de 16.1 via tap sur un fournisseur.

**Exit Action:** Tap "Passer la commande" → 16.3.

**On-Page Interactions:**
- Liste articles du fournisseur sélectionné (depuis catalogue S11)
- `QuantityControl` par article — quantité à commander
- Prix achat + montant total estimé mis à jour en temps réel
- `DatePicker` date de livraison souhaitée (optionnel)
- `TextInput` note pour le fournisseur (optionnel)
- `ActionButton` "Passer la commande" — actif si au moins 1 article avec quantité > 0
