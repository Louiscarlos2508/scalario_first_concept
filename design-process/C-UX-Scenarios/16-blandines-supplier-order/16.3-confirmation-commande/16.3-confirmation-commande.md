# 16.3 — Confirmation Commande

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 16: Blandine's Supplier Order |
| **Step** | 16.3 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** La commande est enregistrée — Ibrahim notifié pour réception future, commande visible en statut "En attente", pipeline commande→réception ouvert.

**Entry Context:** Vient de 16.2 via tap "Passer la commande".

**Exit Action:** `AlertBanner` vert "Commande enregistrée" → retour Dashboard OWNER ✓

**On-Page Interactions:**
- `AlertBanner` vert "Commande enregistrée — en attente livraison" — 2 sec
- Récap commande : fournisseur, articles, quantités, montant estimé, date livraison souhaitée
- Ibrahim reçoit push FCM : "Nouvelle commande — [fournisseur] — réception attendue [date]"
- Commande apparaît dans liste "Commandes en attente" (liée à S05)
