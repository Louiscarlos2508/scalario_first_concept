```

    id         : "cmd-001"
    fournisseur: "Marché Central Adjamé"
    articles   : [{ id: "tomates", qte: 10 }, { id: "igname", qte: 5 }]
    montant    : 10250
    livraison  : "2026-05-12"
    status     : "en_attente"
    created_by : "blandine"
    created_at : "2026-05-09T09:55:00"
  }

S05 utilise (Ibrahim) :
  → Ibrahim voit "cmd-001" dans sa liste "Commandes en attente"
  → Il valide la réception (articles + quantités reçus)
  → commande.status = "reçue"
  → stock.tomates += qte_reçue
  → stock.igname  += qte_reçue
```
