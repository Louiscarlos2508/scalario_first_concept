# 17.1 — Création Tenant

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 17: Kofi's Tenant Deployment |
| **Step** | 17.1 |
| **Platform** | Flutter Web PWA (back-office intégrateur) |

## Overview

**Page Purpose:** Kofi saisit les informations de base du nouveau client et sélectionne le template métier adapté.

**Entry Context:** Back-office Kofi → section "Mes clients" → ActionButton "Nouveau client".

**Exit Action:** Tap "Configurer" → 17.2 pour paramètres détaillés.

**On-Page Interactions:**
- `TextInput` nom de l'entreprise
- `TextInput` adresse / ville / pays
- `ChipSelector` secteur : Retail Alimentaire / Épicerie / Marché / Restauration / Autre
- `TemplateSelector` — liste templates disponibles pour ce secteur (retail_fresh_produce.json mis en avant)
- Aperçu template sélectionné : modules inclus, composants POS, types d'alertes
- `ActionButton` "Configurer" — actif si nom + secteur + template remplis
