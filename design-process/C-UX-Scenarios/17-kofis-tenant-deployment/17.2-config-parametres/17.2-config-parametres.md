# 17.2 — Config Paramètres

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 17: Kofi's Tenant Deployment |
| **Step** | 17.2 |
| **Platform** | Flutter Web PWA (back-office intégrateur) |

## Overview

**Page Purpose:** Kofi configure les paramètres opérationnels du tenant et crée le premier compte OWNER (Blandine) — KYC tenant effectué.

**Entry Context:** Vient de 17.1 via tap "Configurer".

**Exit Action:** Tap "Activer le tenant" → 17.3.

**On-Page Interactions:**
- `ChipSelector` monnaie : FCFA / GHS / XOF / autre
- `ChipSelector` fuseau horaire : Africa/Abidjan / Africa/Accra / autre
- `ImageUploader` logo entreprise (optionnel)
- Section "Compte OWNER" :
  - `TextInput` prénom + nom OWNER
  - `TextInput` numéro de téléphone (= username)
  - Mot de passe temporaire auto-généré (affiché une fois, copyable)
- Section "KYC Tenant" :
  - `TextInput` numéro RCCM ou équivalent local
  - `ChipSelector` type structure : EI / SARL / SA / Autre
  - `Toggle` KYC vérifié (Kofi confirme avoir vu les documents physiquement)
- `ActionButton` "Activer le tenant" — actif si monnaie + compte OWNER + KYC toggle ON
