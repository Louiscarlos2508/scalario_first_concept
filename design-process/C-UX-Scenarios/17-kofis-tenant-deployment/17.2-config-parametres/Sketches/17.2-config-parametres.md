### Sécurité — Mot de Passe Temporaire

```
Génération :
  → 8 chars [A-Z0-9] (exclut: 0/O, 1/I/l pour lisibilité)
  → Exemple : "GH8X4J2T"
  → Généré côté client à l'affichage du formulaire OWNER
  → Jamais sauvegardé en clair dans le state (mémorisé localement jusqu'à activation)

À l'activation (T+0ms) :
  → Haché bcrypt côté backend
  → Jamais transmis en clair dans les API logs
  → Blandine forcée de le changer à la 1ère connexion (S07 flow)
  → Si Kofi recharge la page avant activation → nouveau mdp généré + AlertBanner warning
    "Le mot de passe temporaire a changé — communiquez le nouveau à Blandine"
```
