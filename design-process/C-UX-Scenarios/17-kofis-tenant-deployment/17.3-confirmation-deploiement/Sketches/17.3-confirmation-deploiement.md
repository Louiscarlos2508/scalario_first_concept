### Time-to-Value — Calcul SLA

```
Time-to-value = timestamp_activation − timestamp_création_tenant
  = moment où Kofi clique "Activer le tenant" − moment où Kofi clique "Nouveau client"

Affiché dans :
  → TenantRow de la liste clients Kofi
  → Dashboard intégrateur (stats globales)
  → Rapport Scalario Admin (Carlos) — performance intégrateurs

Objectif Scalario : Time-to-value < 1h = argument commercial
  Kofi #1 : Mon Magasin Abidjan → 42 min (✓ sous la barre)
  Kofi #2 : Épicerie Kouamé     → 38 min (✓)
  Kofi #3 : Marché du Village   → 55 min (✓)
  Moy.    → 45 min              (✓ objectif < 60 min)
```
