# 18.1 — Sélection Périmètre

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 18: Ibrahim's Inventory Count |
| **Step** | 18.1 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Ibrahim choisit le périmètre de l'inventaire — complet (tous les articles) ou partiel par catégorie.

**Entry Context:** Dashboard MANAGER → ActionButton "Inventaire".

**Exit Action:** Tap "Commencer l'inventaire" → 18.2 avec la liste d'articles du périmètre.

**On-Page Interactions:**
- `ChipSelector` périmètre : Inventaire complet / Par catégorie
- Si "Par catégorie" : `FilterChips` catégories disponibles (Fruits, Légumes, Produits secs, Boissons…)
- Aperçu : nb articles à compter selon périmètre sélectionné
- Date et heure inventaire auto-renseignées (timestamp)
- `TextInput` note optionnelle (ex: "Inventaire hebdomadaire — mercredi soir")
- `ActionButton` "Commencer l'inventaire"
