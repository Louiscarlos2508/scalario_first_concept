# Sketch Hi-Fi — 18.2 Saisie Quantités Inventaire (Ibrahim)

> Ibrahim saisit les quantités physiques réelles article par article.
> Stock théorique Drift affiché par article — écart calculé en temps réel.
> Écarts : vert (conforme) / bleu (surplus) / ambre (déficit faible) / rouge (déficit fort).
> Progression : "X/Y articles comptés" — CTA "Valider" actif quand tous saisis.

```json

  "ecart_faible_pct":    5,   // 0-5% → conforme (vert)
  "ecart_moyen_pct":    15,   // 5-15% → déficit faible (ambre)
```
