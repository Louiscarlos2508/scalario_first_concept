### Logique statut stock

```
critique  : stock_actuel < seuil_alerte_stock  → border-l danger-400 + badge danger
normal    : seuil_alerte ≤ stock_actuel ≤ seuil_surplus → border neutral + badge success
surplus   : stock_actuel > seuil_surplus       → border-l primary-300 + badge primary
```

→ seuils depuis retail_fresh_produce.json par article
→ Tomates : seuil_alerte=20 · stock=12 → critique
→ Bananes : seuil_alerte=30 · stock=25 → critique
→ Oignons : seuil_surplus=8 · stock=10 → surplus
→ Reste : normaux
