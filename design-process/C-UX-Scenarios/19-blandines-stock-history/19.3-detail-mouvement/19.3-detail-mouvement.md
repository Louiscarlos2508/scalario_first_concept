# 19.3 — Détail Mouvement

## Page Metadata

| Property | Value |
|----------|-------|

| **Step** | 19.3 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine zoome sur un mouvement spécifique pour en comprendre le contexte complet — qui, quoi, quand, pourquoi.

**Entry Context:** Vient de 19.2 via tap sur un mouvement.

**Exit Action:** Compréhension atteinte → retour historique article ✓

**On-Page Interactions:**
- Titre contextuel : "Perte déclarée — Tomates — 12 mai"
- Détail complet selon type :
  - Vente : articles, commercial, montant, mode paiement
  - Livraison : fournisseur, articles, écarts éventuels, validé par Ibrahim
  - Perte : article, quantité, nature (avarié/casse/vol/autre), note, déclaré par Ibrahim
  - Inventaire : stock théorique, stock réel, écart, note Ibrahim
- Stock avant / après mouvement visible
- Lien vers transaction d'origine (optionnel — Phase 2)
