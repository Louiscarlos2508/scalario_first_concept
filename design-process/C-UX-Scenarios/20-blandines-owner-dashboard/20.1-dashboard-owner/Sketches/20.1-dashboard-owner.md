### Hiérarchie conditionnelle

```
if alertes_actives:
  Zone 1 AlertBanner (rouge si critique, ambre si warning)
  → KPIs dessous

elif créances_echues:
  Zone 1 AlertBanner ambre créances
  → KPIs avec ligne Créances séparée du CA

else:
  Pas de zone alertes → KPIs directement sous MiniTopBar
  KPICard "Stock critique" → "Stock OK" bg success-50
```

### Règle CA vs Créances

```
CA du jour = Σ(montants versés en espèces + virements reçus)
           ≠ Créances (montants dus mais non encaissés)

→ KPICard CA = encaissé uniquement (label: "CA encaissé (hors crédit)")
→ KPICard Créances = dûes non reçues (bg warning-50 distinctif)
→ jamais additionner CA + Créances dans un même total
```
