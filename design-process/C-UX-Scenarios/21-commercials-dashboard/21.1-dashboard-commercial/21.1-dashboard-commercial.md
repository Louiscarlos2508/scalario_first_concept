# 21.1 — Dashboard COMMERCIAL

## Page Metadata

| Property | Value |
|----------|-------|

| **Step** | 21.1 |

## Overview

**Page Purpose:** Dashboard ultra-épuré centré sur l'action — POS en 1 tap, chiffre du jour, historique ventes récentes.

**Entry Context:** Biometric/PIN unlock → dashboard COMMERCIAL.

**Exit Actions:**
- Tap "Nouvelle vente" → S02 (quick sale)
- Tap "Clôture caisse" → S03
- Tap transaction historique → S14 (sale return)

## Principes de Design Dashboard COMMERCIAL

- **Un seul geste** — "Nouvelle vente" accessible sans scroll sur tout appareil Android
- **Pas de KPIs globaux** — Commercial voit uniquement ses propres chiffres (pas le CA total magasin)
- **Pas d'alertes stock** — ce n'est pas son rôle — géré par Blandine (S04) et Ibrahim (S05/S06)
- **Offline transparent** — si offline, POS fonctionne depuis Drift — SyncStatusBar discret
