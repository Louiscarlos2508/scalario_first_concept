### BottomNav COMMERCIAL — 3 tabs

```
🛒 Vente  │  🏠 Dashboard  │  📋 Historique

Vente     : ouvre directement S02.1 (sélection articles POS) — POS accessible en 1 tap depuis n'importe quel écran
Dashboard : vue KPIs + "Nouvelle vente" + historique récent
Historique: S14.1 liste toutes ventes du jour

→ "Nouvelle vente" sur Dashboard = raccourci alternatif (= même destination que onglet Vente)
```

### Règles métier COMMERCIAL

```
KPIs personnels uniquement :
  → Commercial voit son propre CA (pas le CA global boutique)
  → Source : transactions où auteur_id = commercial_connecté

Pas d'alertes stock :
  → Pas d'AlertBanner rouge stock critique (rôle OWNER/MANAGER uniquement)
  → Commercial focus 100% sur la vente

ActionButton "Nouvelle vente" invariant :
  → Toujours above fold · jamais masqué par une alerte ou un scroll
  → h=64px → intentionnellement plus grand que toutes autres actions
  → ACTIF même offline (Drift local)
  → Même destination que onglet "Vente" dans BottomNav

Clôture caisse conditionelle :
  → Visible après heure_seuil (configurable dans retail_fresh_produce.json : 17h30 par défaut)
  → Disparaît après clôture effectuée → ActionButton "Nouvelle vente" = disabled
```
