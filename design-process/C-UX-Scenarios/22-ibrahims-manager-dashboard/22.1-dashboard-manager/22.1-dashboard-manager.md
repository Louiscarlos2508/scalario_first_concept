## Page Metadata

| Property | Value |

## Overview

**Page Purpose:** Dashboard orienté tâches terrain — Ibrahim voit ce qui l'attend aujourd'hui et accède directement à ses actions.

**Entry Context:** Biometric/PIN unlock → dashboard MANAGER.

**Exit Actions:**
- Tap AlertBanner commande → S05 (delivery validation)
- Tap "Réceptionner livraison" → S05
- Tap "Déclarer une perte" → S06
- Tap "Inventaire" → S18

---

## Principes de Design Dashboard MANAGER

- **Tâches avant métriques** — AlertBanner commandes en attente est la première info visible
- **3 actions max** — Réceptionner / Déclarer perte / Inventaire — pas plus
- **Pas de CA ni marge** — ce n'est pas son rôle — réservé à Blandine (S20)
- **Offline first** — toutes les actions terrain fonctionnent sans réseau (Drift)
