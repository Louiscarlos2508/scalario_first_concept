# 23.1 — Forced Password Change

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 23: First Login Password Change |
| **Step** | 23.1 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Écran bloquant au premier login — Blandine doit définir son propre mot de passe avant d'accéder à l'app. Pas de retour en arrière possible.

**Entry Context:** S07.1 login avec mot de passe temporaire → système détecte `force_password_change: true` → redirect immédiat.

**Exit Action:** Nouveau MDP confirmé → redirect vers S24 (setup PIN/biométrie) ou Dashboard.

**On-Page Interactions:**
- Message contextuel : "Bienvenue ! Kofi a créé votre compte. Définissez votre mot de passe personnel."
- `TextInput` nouveau mot de passe (masqué, révélable)
- `TextInput` confirmation mot de passe
- Indicateur de force du mot de passe en temps réel
- Règles visibles : min 8 caractères, 1 chiffre, 1 majuscule
- `ActionButton` "Définir mon mot de passe" — disabled jusqu'à validation
- Pas de bouton retour — écran bloquant
