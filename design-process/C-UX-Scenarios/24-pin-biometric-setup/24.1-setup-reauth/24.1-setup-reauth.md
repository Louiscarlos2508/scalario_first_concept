# 24.1 — Setup Re-auth

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 24: PIN / Biometric Setup |
| **Step** | 24.1 |
| **Platform** | Mobile Android (PIN + biométrie) / Flutter Web PWA (PIN uniquement) |

## Overview

**Page Purpose:** L'utilisateur choisit sa méthode de déverrouillage rapide et la configure en quelques taps.

**Entry Context:** Après S23 (automatique) ou depuis Paramètres → Sécurité.

**Exit Action:** Configuration validée → `AlertBanner` vert "Déverrouillage configuré" → Dashboard ✓

**On-Page Interactions:**
- `ChipSelector` méthode : PIN / Empreinte / Face ID (options disponibles selon appareil)
- Si PIN : clavier numérique 4–6 chiffres, saisie + confirmation
- Si Empreinte : redirection vers dialogue système Android (hors app)
- Si Face ID : redirection vers dialogue système Android (hors app)
- Option "Passer pour l'instant" (skipable — peut configurer plus tard depuis Paramètres)
- Note : "Si vous oubliez votre PIN, vous pouvez toujours vous connecter avec votre mot de passe"

## FCM Permission (Android 13+)

Si l'utilisateur n'a pas encore accordé la permission notifications push, elle est demandée **juste avant** ou **juste après** le setup re-auth — jamais au milieu. Le dialogue système Android apparaît une seule fois.
