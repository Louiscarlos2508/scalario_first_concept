# 25.1 — Vue Profil

## Page Metadata

| Property | Value |

## Overview

**Page Purpose:** L'utilisateur voit ses informations de profil actuelles et accède aux options de modification.

**Entry Context:** Paramètres → "Mon profil" ou avatar utilisateur.

**Exit Action:** Tap "Modifier" → 25.2 formulaire.

**On-Page Interactions:**
- Avatar initiales (pas de photo pour Gate 0)
- Nom complet, rôle, tenant (entreprise)
- Numéro de téléphone (= username)
- Méthode déverrouillage active (PIN / Empreinte / Face ID)
- Dernière connexion
- `ActionButton` "Modifier mes informations" → 25.2
- `ActionButton` "Modifier le déverrouillage" → S24
- `ActionButton` "Changer mon mot de passe" → 25.2 (section MDP)
- `ActionButton` destructif "Se déconnecter" → logout + retour S07
