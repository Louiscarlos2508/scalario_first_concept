# 25.2 — Edit Profil

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 25: Profile Settings |
| **Step** | 25.2 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Formulaire de modification du profil — nom, téléphone, mot de passe.

**Entry Context:** Vient de 25.1 via tap "Modifier".

**Exit Action:** Tap "Sauvegarder" → `AlertBanner` vert → retour 25.1 avec données mises à jour.

**On-Page Interactions:**
- `TextInput` prénom (pré-rempli)
- `TextInput` nom (pré-rempli)
- `TextInput` téléphone (pré-rempli — modification avec re-validation)
- Section "Changer le mot de passe" (optionnelle — collapsible) :
  - `TextInput` mot de passe actuel
  - `TextInput` nouveau mot de passe + indicateur de force
  - `TextInput` confirmation nouveau MDP
- `ActionButton` "Sauvegarder" — actif si au moins 1 champ modifié et valide
- Changement de téléphone : re-demande confirmation MDP actuel (sécurité)
