# 26.1 — Fond de Caisse

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 26: Ouverture de Caisse |
| **Step** | 26.1 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Commercial déclare le montant cash initial en caisse avant la première vente.

**Entry Context:** Dashboard COMMERCIAL → tap `AlertBanner` ambre "Aucune session active" ou tap `ActionButton` "Ouvrir la caisse".

**Exit Action:** Tap "Confirmer l'ouverture" → 26.2 confirmation session active.

**On-Page Interactions:**
- `AlertBanner` info — rappel du fond de caisse de la veille (dernière fermeture)
- `NumberInput` montant fond de caisse (FCFA) — clavier numérique natif
- `TextInput` note optionnelle (ex: "reçu billet 5000 de Blandine")
- `ActionButton` "Confirmer l'ouverture" — actif dès qu'un montant ≥ 0 est saisi
- Lien "Ouvrir avec fond 0 FCFA" — si caisse vide (session test)
