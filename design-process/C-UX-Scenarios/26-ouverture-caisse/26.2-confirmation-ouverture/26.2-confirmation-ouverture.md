# 26.2 — Confirmation Ouverture

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | 26: Ouverture de Caisse |
| **Step** | 26.2 |
| **Platform** | Mobile Android |

## Overview

**Page Purpose:** Confirmation que la session caisse est active — Commercial peut commencer à vendre.

**Entry Context:** Vient de 26.1 après validation du fond de caisse.

**Exit Action:** Tap "Commencer les ventes" → Dashboard COMMERCIAL (session active).

**On-Page Interactions:**
- `AlertBanner` vert — "Session ouverte — Fond de caisse : 15 000 FCFA"
- Récap horodaté : heure d'ouverture, utilisateur, fond déclaré
- `ActionButton` "Commencer les ventes" → retour Dashboard COMMERCIAL
- Notification push envoyée à Blandine : "Session ouverte par [Prénom] à 08h15 — Fond : 15 000 FCFA"

**Comportement offline :**
Si pas de réseau : session ouverte localement (Drift), sync au retour réseau. `SyncStatusBar` ambre.
