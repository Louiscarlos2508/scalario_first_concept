# 27.1 — Ticket de Caisse

## Overview

**Page Purpose:** Génération et partage du ticket de caisse simple après une vente cash (S02.3).

**Entry Context:** Vient de S02.3 (confirmation vente cash) via `ActionButton` secondaire "Partager le ticket" ou `BottomSheet` de partage automatique.

**Exit Action:** Ticket envoyé → fermeture `BottomSheet` → retour Dashboard COMMERCIAL.

**On-Page Interactions:**
- `BottomSheet` compact avec aperçu du ticket (nom tenant, articles, total, heure)
- `ChipSelector` canal : [WhatsApp] [SMS] [Impression] [Ignorer]
- `ActionButton` "Envoyer" — déclenche le partage selon le canal sélectionné
- Si Impression : recherche imprimante Bluetooth + progression
- Tap "Ignorer" → fermeture sans envoi (aucune obligation)

**Comportement par défaut :**
Canal pré-sélectionné selon config tenant (JSON). Si `send_receipt_default: whatsapp` → WhatsApp pré-coché.
