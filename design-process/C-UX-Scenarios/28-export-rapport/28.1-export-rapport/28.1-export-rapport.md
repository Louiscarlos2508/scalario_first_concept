# 28.1 — Export de Rapport

## Page Metadata

| Property | Value |
|----------|-------|

| **Step** | 28.1 |
| **Platform** | Mobile Android OU Flutter Web PWA |

## Overview

**Page Purpose:** Blandine exporte le rapport de la période sélectionnée (S12) en PDF ou CSV et le partage.

**Entry Context:** Vue Rapport S12.2 → `ActionButton` "Exporter" ou icône export dans l'AppBar.

**Exit Action:** Fichier généré et partagé → retour S12.2.

**On-Page Interactions:**
- `BottomSheet` medium — choix format et canal
- `ChipSelector` format : [PDF] [CSV]
- `ChipSelector` canal : [WhatsApp] [Email] [Télécharger]
- `ActionButton` "Générer et partager"
- Période exportée = période sélectionnée dans S12 (aujourd'hui / semaine / mois / perso)
- `LoadingSpinner` pendant génération (PDF peut prendre 2-3 sec)

**Règle offline :**
Export disponible uniquement si les données sont en cache Drift. Si données partielles → `AlertBanner` ambre "Données partiellement disponibles — export incomplet possible".
