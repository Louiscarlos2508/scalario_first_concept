# Sketch Hi-Fi — 28.1 Export de Rapport

> Blandine exporte le rapport de la période en PDF ou CSV et le partage.
> Platform : Mobile Android + Flutter Web PWA.
> Entry : S12.2 Vue Rapport → ActionButton "Exporter" ou icône export AppBar.
> Exit : Fichier généré et partagé → retour S12.2.

### Règle offline export

```
CSV uniquement offline (Drift local) :
  → CSV = données Drift → instantané · toujours disponible
  → PDF = backend → nécessite connexion → grisé offline

Données partielles :
  if (dernière_sync > 2h) : AlertBanner ambre "données partielles"
  if (aucune_donnée_drift) : AlertBanner danger · CTA disabled

→ Honnêteté avant tout : Blandine sait que son rapport peut être incomplet
```
