# Composite — POS Flow (Point de Vente)

> Le flow le plus fréquent de toute l'app.
> Grille de cartes produits → panier → paiement → confirmation.
> Règle : 3 taps du dashboard à la confirmation. Zéro friction.

---

## Structure Globale POS

```
┌──────────────────────────────────────────────┐
│ ← NOUVELLE VENTE                      [✕]   │  AppBar
├──────────────────────────────────────────────┤
│ 🔍 Rechercher...  [● Légumes] [○ Fruits] →  │  Recherche + Catégories
├──────────────────────────────────────────────┤
│                                              │
│  GRILLE PRODUITS (scrollable)                │
│                                              │
├──────────────────────────────────────────────┤
│ 🛒 Panier — X articles          XX XXX F     │  Barre panier fixe (sticky)
│                 [ Procéder au paiement → ]   │
└──────────────────────────────────────────────┘
```
