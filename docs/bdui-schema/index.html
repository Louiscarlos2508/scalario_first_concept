Definitions

Rule

Règle conditionnelle récursive. Les opérateurs logiques (AND, OR) ont des enfants ; les opérateurs de comparaison comparent un champ à une valeur ; l'opérateur 'role' teste l'appartenance de l'utilisateur à un rôle.

FieldTypeRequiredDescription
operatorenum: AND, OR, role, >, <, ==, !=, >=, <=, in, not_inYesOpérateur de la règle. AND/OR = logique binaire avec children ; role = test d'appartenance ; comparaisons = test de valeur.
childrenarrayNoSous-règles pour les opérateurs logiques AND/OR. Requis si operator ∈ {AND, OR}.
fieldstringNoChamp évalué par l'opérateur de comparaison. Chemin dot-noté (ex: 'order.total', 'user.department_id').
valueobjectNoValeur de comparaison. Type libre (string, number, array) selon l'opérateur. Pour 'role', c'est le nom du rôle ou un tableau de rôles.
negatebooleanNoSi true, inverse le résultat de la règle (équivalent à NOT).

DataSource

Déclaration d'une source de données pour un composant BDUI. Le moteur résout la source au runtime via DataSourceResolver.

FieldTypeRequiredDescription
typeenum: module_data, kpi, static, computedYesType de source. module_data = données d'une entité du module ; kpi = agrégat pré-calculé ; static = données en dur dans props ; computed = formule ou expression.
module_idstringNoIdentifiant du module source, requis si type ∈ {module_data, kpi}.
queryobjectNoParamètres de requête. Structure permissive — chaque type de source définit ses propres paramètres.

ValidationRule

Règle de validation côté client pour un champ de formulaire.

FieldTypeRequiredDescription
kindenum: required, min, max, pattern, min_length, max_lengthYesType de validation. required = champ obligatoire ; min/max = valeurs numériques ; pattern = regex ; min_length/max_length = longueur texte.
valueobjectNoValeur seuil pour la validation. Type dépend de kind : number pour min/max, string pour pattern, integer pour min_length/max_length. Ignoré pour 'required'.
message_i18n_keystringNoClé i18n du message d'erreur affiché si la validation échoue.
